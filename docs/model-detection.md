# 模型检测与通知

OpenAI OAuth 与 Key 的三类明确上游降智错误和慢首字预警只作为模型检测线索，不直接发送 Bark。独立采集任务每两秒读取既有记录；同一账号所有自动模型检测共用五分钟门限，冷却中的重复线索直接忽略。只有首组有效指纹判定降智、标记保存并确认停止调度后，才发送结果通知，失败按 5/30/120/600 秒独立重试。采集水位、标记、冷却与通知状态持久化为权限 `0600` 的独立文件，升级不补发历史通知或补跑历史线索，不修改数据库表。

定时检测仅在账号“允许调度”开启时执行，已标记降智的账号也遵守此规则。关闭调度后保留检测设置，重新开启后按保存的间隔重新计时，不补跑错过的检测。有效复查确认恢复正常并取消标记后，发送独立恢复通知，保持当前调度状态。失败或分析不足不会清除标记，人工操作始终优先。Codex 点数与额度窗口独立判断：有可用点数或无限额度时，百分比满额不阻止检测；点数未知且无当前阻断时继续按计划执行，不增加额度查询。

## 判定规则

请求模型使用任务保存的 `requested_model`，不使用映射后的转发模型。比较前去除首尾空白并忽略大小写。

1. 预测为空或报告没有有效输出时，不形成有效检测结论，不能据此解除标记。
2. 预测为 `gpt-5.6-luna` 一律判定降智，包括请求本身也是该模型的情况。
3. 其他相同模型不判定降智。仅 `astra > sol > luna` 参与等级比较；`terra`、无后缀、未知等级、非 GPT 或格式不合法的模型不参与新增比较，仍保留上一条强制规则。
4. 等级优先：预测等级更低即降智，更高则不降智。同等级按版本号的数字段比较，预测版本更低才降智；`6` 等同于 `6.0`，`5.10` 大于 `5.9`。

| 请求 | 指纹预测 | 降智判定 |
|---|---|---|
| `gpt-6.1-sol` | `gpt-6-astra` | 否，等级更高 |
| `gpt-6-astra` | `gpt-6-sol` | 是，等级降低 |
| `gpt-6-sol` | `gpt-6-luna` | 是，等级降低 |
| `gpt-6-luna` | `gpt-5.9-sol` | 否，等级优先于版本 |
| `gpt-6-sol` | `gpt-5.6-sol` | 是，同等级版本降低 |
| `gpt-6.1-astra` | `gpt-6-astra` | 是，同等级版本降低 |
| `gpt-6-astra` | `gpt-6.0-astra` | 否，版本等价 |
| `gpt-5.10-sol` | `gpt-5.9-sol` | 是，按数字比较 |
| `gpt-5.6-luna` | `gpt-5.6-luna` | 是，强制规则优先 |
| `gpt-6-sol` | `gpt-5.6-terra` / `gpt-5.5` / `claude-sonnet-5` | 不参与新增比较 |

未命中降智规则不等于请求成功；完成状态、有效输出和原有恢复条件仍须满足。指纹库必须包含 `gpt-5.6-luna` 的原有检查继续保留。库中缺少请求模型不会额外阻断检测，仅输出不含原始模型文本的原因诊断。

## 首组、汇总与复查

自动检测以首组的有效报告决定提前结束、标记及确认，通知仍显示“首组指纹推测”。重试第一组时单独分析该组，不能用其他组的汇总代替首组证据。最终报告用于结果展示，两种报告应用相同的模型比较规则。

取消降智标记需要首组和最终报告均未判定降智，并满足原有的有效输出、完成组、无错误及不可重试等条件。首组正常而汇总降智时不能清除既有标记，也不因此新增首组自动处置。恢复模型验证同样使用任务请求模型；手动模型测试不自动标记或停止调度。

判定调整不改变模型映射、白名单、五分钟冷却、账号互斥及人工控制优先规则。升级不批量重判历史任务，不重放已确认处置、已发送通知或结果未知的请求。
