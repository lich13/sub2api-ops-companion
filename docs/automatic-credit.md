# 自动用卡

自动用卡从本轮原始 7d 满额且发生有效上游限流的时间起，最多等待五分钟；过期不补执行，重复限流和重启不刷新期限。卡资格按当前账号中有效、未过期的可用卡数判断，旧卡观测的数量或时间不再阻止用卡；当前卡数缺失、无效或为零时跳过。每轮唯一一次消费豁免一小时查询间隔，但仍计入滚动 24 小时六次预算；普通查询规则不变。消费明确成功后，五分钟内最多两轮恢复验证，仍遵守模型检测冷却。最终结果通过 Bark 通知，投递最多五次；未知消费禁止重放，只有消费、验证和恢复调度都确认成功才计入用卡恢复历史。

验证成功后的清状态及启用调度失败沿用原截止时间重试，不重复扣卡。释放前检查验证结果、暂停归属、人工控制和当前额度；清状态成功后仅核对账号仍存在且为 active，再启用调度并读回确认。

在本应用或上游删除账号后，当前自动用卡任务静默结束，所有尚未发送的用卡通知均停止，包括已扣卡结果；已发送通知无法撤回。历史和扣卡回执保留，缺少来源且没有派发证据的旧手动记录不会转成自动任务。
