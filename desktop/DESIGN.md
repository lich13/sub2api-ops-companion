# Sub2Ops 桌面设计

这是持续运行的运维控制台。优先看清最近成功调用、当前调度和错误证据，再执行准确的单账号操作。

- 采用 Linear 参考中的紧凑层级和细分隔线，适配 macOS 系统字体及深浅主题；不使用其专有字体或品牌素材。
- 浅色：画布 #f5f6f9、表面 #ffffff、正文 #202432、次要文字 #707789、强调 #6262ce、边线 #e5e7ed。深色使用 #17191f、#20232b、#ebedf3、#969eaf、#9797ef、#333844。
- 字号 12 / 13 / 14 / 18 / 26；数字等宽，代码才使用等宽字体。正文左对齐，数值右对齐。
- Mac 主窗口默认 1310×860，按当前屏幕可用区缩小并居中；侧栏 176px，较窄屏幕 144px。八列账号表为调度和操作预留固定宽度，名称省略，用量可换行；手动缩窄时仅表格横滚。首次初始化设置尺寸，再次打开不覆盖用户本次调整。错误详情为右侧抽屉。
- 快捷面板宽 420px，高度随内容收缩，最高 520px；36px 单行工具栏包含分组 / 异常、连接状态、刷新、固定、关闭，底栏 28px。超过高度后仅内容滚动，不留固定底部空白。
- Android 使用五项底部导航及单列账号块，触控区至少 48dp。搜索常驻，筛选和账号操作进入弹层，详情与测试全屏显示；分组动态由账号页进入。系统返回先关闭当前弹层，再返回账号页，账号页返回后台。适配系统栏、输入法与底部安全区，不显示 Mac 专属选项。
- Mac 主窗口入口为账号、分组、优先级、记录、事件、功能、设置，默认账号页；Android 保留五项底部导航，账号页提供分组管理和优先级管理入口。侧栏不显示工作区块或域名。账号名称和平台类型合并，名称省略时悬浮显示完整内容；优先级只读，通过独立优先级页修改；本机记住上次显示排序，首次按最近调用倒序。
- 每组展示最近成功调用的三个不同账号，排除已删除账号；按最近调用时间排序，未调用分组置底。组标题 24px、组间距 6px、账号行 48px。左列为名称和 OAuth 微型用量，右列为最近调用 / 上次错误两项时间，最右调度开关。名称省略并提供完整悬浮提示，错误时间可进入详情。稳定账号键和滚动容器，仅内容高度变化调整原生窗口，轮询不重置位置。
- 快捷面板中受限账号名称使用琥珀色并附原因提示，仅可恢复账号显示小型恢复按钮；调度开关保持独立。分组行在原右侧操作槽内上下排列恢复按钮和开关，异常行的详情和恢复为独立按钮。
- OpenAI Key 的定时检测增加模型选择，候选与模型测试共用，可选择跟随全局；模型不可用时保留原选择并提示。
- 定时检测在现有信息区显示服务端记录的上次开始时间；未知时间如实标记，保存设置与页面刷新不产生检测时间。
- 账号选择只作用于当前筛选结果；单个和批量删除均确认名称、编号及数量，逐账号显示结果，失败项保留选择。零选择时不显示批量操作栏，Android 全选保留在数量与排序行。关闭测活结果后不保留摘要横条，结果从既有工具栏重新打开。恢复状态直接执行，与连接测试、调度等操作共用账号锁。
- 事件页为降智错误、其他错误、恢复历史和日志四个标签，独立刷新、分页和滚动。日志使用十列横表，窄屏横向滚动；结论、恢复回执及通知分别展示，不用整行颜色推断正常。历史名称与已有证据保留，详情按指定任务打开。
- 限流展示琥珀色状态标签、自动解除倒计时和原因提示，悬浮保留北京时间的准确解除时间；仅仍有限流且最近错误后没有成功调用时附最近 HTTP 429 入口。倒计时到点显示等待状态刷新，不自行确认恢复；恢复成功分别展示测活通过和状态确认时间。旧记录缺少证据时显示时间未知。
- 连接测试以单个弹窗承载模式、模型、必要素材和流式结果；开始按钮直接执行，不增加确认步骤；输出保留空格、换行和缩进。耗时操作与实时快照读取独立，取消不重试。
- 最近报错区域在错误证据下独立展示所有账号的最后成功调用时间；只有成功晚于最近错误时显示绿色并保留成功提示，其他情况使用次要文字色。Mac 与 Android 沿用原错误详情入口，标签可换行。
- 时间统一为北京时间 `MM-DD HH:mm:ss`，包括悬浮提示。没有记录显示“暂无记录”，无效时间显示“时间未知”；除账号限流解除倒计时外不使用相对时间，后端保留完整年份。
- 用量栏按 Sub2API a3eb7ef 的 AccountUsageCell / UsageProgressBar 对齐：统计标签（9px）在上，32px 窗口徽章、32×6px 进度条、32px 百分比及准确重置时间（10px）在下。75% 为琥珀色、90% 为红色。5h 靛蓝、OpenAI 7d 翠绿，Grok 7d/30d 靛蓝、免费 24h 翠绿；Key 总配额紫色。
- OpenAI OAuth 显示适用的 5h/7d；Grok 付费显示官方 7d/30d 及适用预付余额，免费显示 24h；API Key 显示今日统计和已配置的日/周/总配额。统计含缓存 Token，A 含账号倍率、U 为实际费用。未知不显示为 0%，历史或失败保留简短状态，采集时间收进悬浮提示。
- 保留查询、次数、重置和探测的适用入口，排除点数与邀请。重置和模型探测必须明确确认，防重复提交；失败不重放，先读取实际状态。
- 删除解释性副标题、连接教学、实现原理和装饰口号。保留真实状态、错误原因及删除等必要确认。
- 账号与分组使用列表、表格；不堆叠无意义的数字卡片。状态始终有文字和图标，不只靠颜色。
- 蓝紫色用于选择与操作；红色用于错误，琥珀色用于冷却，绿色用于正常。调度开关和可用性是独立字段。
- 所有操作具备加载、失败、禁用和键盘焦点状态。离线不允许提交或重放操作。
- 菜单栏左键始终显示并聚焦面板，重复点击不隐藏；真正失焦时关闭，固定状态除外。Escape 和关闭按钮均可关闭。主窗口关闭驻留菜单栏，主窗口打开或最小化时显示 Dock 图标，关闭后隐藏；快捷面板不影响 Dock。减少动态效果，尊重 reduced-motion。
- 验收包括原生窗口与 Browser：深浅主题、窄面板、键盘、长账号名、错误正文、滚动、空与离线状态。

- 功能页顶部使用恢复与检测、模型配置、IP 管理、Sub2API 配置四个标签，每个分区占完整内容宽度，切换保留表单草稿。IP 管理筛选与操作分行，选择后集中显示批量操作；桌面固定名称及操作列，延迟与质量上下排列，宽度不足仅表格横滚。Android 使用纵向列表及全屏编辑与报告，触控区域至少 48px。认证默认遮蔽，显式查看、复制和文件导出按需读取，不添加统计卡片。模型配置占完整内容宽度，只展示分组工具栏、添加模型及已有补全行。行内包含精确模型 ID、档位、默认值、状态、编辑 / 移除；不列出全部原生模型。约 460px 弹窗只保留 ID、档位选择和默认值，来源及限制折叠展示。白名单仅在阻挡当前新模型时显示精确追加确认。保存为单一动作；限制与未知明确标记为草稿，冲突保留输入。原生已支持时提供恢复原生，不显示 JSON、上下文或目录搜索。

- 记录页直接读取已有调用记录。Mac 固定表头与用户列、数字右对齐、宽表独立横滚；Android 使用纵向记录块，沿用字段偏好，详细标识与精确值可在全屏详情查看复制。默认 API 密钥、账户、模型、类型、推理强度、Token、费用、延迟、User-Agent、IP 及用户、时间；列偏好存本地，已有自定义列和空选择保持原样。请求、映射、转发、返回按历史证据展示，合并相同阶段，返回差异加文字标记。完整标识、Token 和费用位于侧边详情。
- 用户与 API 密钥使用可搜索、连续分页的完整目录，名称与 ID 分层展示；选择用户限定其密钥，切换用户清空密钥。目录包含停用及软删除项，历史 ID 可直接筛选。
- Token 上排为绿色输入箭头与紫色输出箭头，下排分别用青色缓存读取、琥珀色缓存写入；缓存缩写为 K/M，详情保留整数。实扣绿色，账户费用橙色。延迟为首字、总耗时、TPS 三行，首字按 10/30/60 秒、总耗时按 60/180/300 秒使用绿/黄/橙/红，细竖条上下对应两项耗时。TPS 中性色，数值保留两位小数；未知显示破折号。
- 记录页仅在前台可见时每 10 秒检查新增；阅读历史或详情时保留位置并显示新增条数。记录不接入快照轮询或任何额度、测活请求。

- 日期控件默认今天，按北京时间提供今天、昨天、近24小时、近7/14/30天、本月、上月及自定义日期。按 Sub2API 口径，近24小时包含昨天和今天两个自然日；结束日期含整日。应用才提交，关闭放弃草稿。
- 记录筛选下显示全部匹配记录的用户实扣总消费，使用历史精确金额，分页不改变汇总。列表与汇总同时更新；阅读历史或跨日时保留位置并提示刷新，失败不显示假零值。
- Android 主页面及弹层以纵向浏览为主，检测日志保留横表滚动：搜索优先，恢复事件改纵向行，分组动态时间独立成行，模型档位换行，输入表单标签置顶。日期和筛选进入适配屏宽弹层；长字段换行或在详情展示，不裁切隐藏宽内容。桌面表格保留现状。

- 分组与优先级按实际账号和分组生成平台入口，未知平台保留原标识；草稿与应用保持平台隔离。分组界面以蓝紫、青色大圆角轮廓相交，独有与共有账号自动排列；待分组和其他分组在下方。左右位置按分组既有顺序固定，不随调用排序。账号名称、ID、类型及必要异常紧凑分层；不显示额外统计卡片或常驻操作教学。
- 拖放只改分组草稿；统一应用，支持撤销、变更明细和冲突处理。Android 将左右独有及共有区纵向排列，长按拖柄；账号名称为普通展示，不再提供点击选中与目标选择条；全页只纵向滚动。
- Codex OAuth 的手动「降智」标签为琥珀色图标加短文字，只在已标记账号显示。账号操作、分组菜单和错误详情提供标记／取消；立即单独保存，不进入分组草稿。

- 优先级页按实际平台分栏。并列值为 1 时从 1 顺序编号，大于 1 时保留实际优先级。桌面内容区至少 960px、至多三个平台且每栏满足 `max(320px, 并列值 × 220px + 72px)` 时并排，栏距 12px；否则使用平台标签。沿用细分隔线与主题表面，各栏名称、账号数和改动数分层，列表独立滚动，底部应用区可见。账号名 13px，状态与数字 12px，ID 和类型 11px；数字等宽并右对齐。仅草稿变化与插入线使用强调色，保留必要错误和等待原因。
- 每个平台独立撤销、放弃与应用。只能同平台拖动，跨栏取消；其他平台任务运行时可继续编辑草稿，不能提交。移动端长按拖柄与按钮目标至少 48px，标签切换保留草稿与滚动位置；搜索时只读。任务进度用实际确认数量及简短状态展示，不加解释性副标题或装饰卡片。

- 分组与优先级账号行使用共用调度开关，保持独立点击区域，不参与拖动。优先级运行状态置于操作区，不显示进度方框或逐项详情；终态结果 3 秒后消失，失败恢复入口仍可用。批量连接测试终态确认后按固定截止时间在 3 秒内收起，删除独立重开入口。

- 优先级并列值按平台独立设置（1–8）。值为 1 时沿用顺序编号；大于 1 时保留实际优先级，每级铺设等宽账号槽，空槽只显示虚线轮廓和加号。拖入空槽只改变该账号的优先级；占用槽之间交换。窄屏将同级槽纵向排列，平台切换保留草稿，不添加操作教学文字。
- 单账号测试连接使用完整上游目录。执行方式为立即或指定时间，预约使用北京时间的日期与分钟，仅执行一次；待执行项可取消，终态记入恢复历史。保持现有自动模型检测设置独立。

- Sub2API 配置使用紧凑分组表单，填满功能标签下的剩余窗口；桌面分组与字段分别滚动，底部操作区独占布局行，不覆盖字段。窄窗口／手机改分组选择和单列；短屏将标题、筛选、字段合并滚动，底部检查与应用保持可达。字段以中文作用为主、完整路径为辅，右侧编辑，默认值与范围紧邻控件；长说明、源码和内部字段可展开，错误与只读覆盖原因常显。搜索／修改筛选跨组汇总，大分组按路径前缀跳转子节；错误定位并聚焦输入。默认字段直接编辑，明确区分未配置、空值、显式默认和删除恢复；差异确认显示新增／修改／恢复默认。
- IP 检测详情按原文展示和复制，保留换行、缩进与完整长错误；使用纯文本和断行，不截断或遮蔽。

- 账号模型目录持久缓存并共用，模型选择框旁使用同尺寸刷新按钮；刷新保留当前选择，失败显示错误。测活模型和自动检测模型使用来源账号与可搜索候选，允许手动输入 ID，不添加解释性小字。
- 记录平台筛选与其他条件保持桌面单行，按可用宽度调整控件，字号一致；手机沿用筛选弹层。恢复历史增加尝试次数，包含首次，未知显示“—”。
- 记录平台、用户、账号、密钥与返回差异选择即生效，模型输入停顿 300ms 或回车生效；手机保留打开筛选面板的入口，关闭保留已生效条件。
- 模型测试的判定模式与降智模型使用等宽网格，窄屏单列；标签、输入及错误使用同一正文规格。模式选中即保存，目标回车或失焦保存，保存中或失败时禁用开始测试；保留简短错误与重试，不添加解释性小字。

- 桌面与 Android 的导航、标签入口不显示事件数量或同类通知计数徽标。保留列表内操作所需的数量与分页。
