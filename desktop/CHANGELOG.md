# Sub2Ops 发布记录

这里记录公开版本的主要变化。每个版本按“新增、改进、修复、兼容”说明实际影响；构建包和校验值以对应 GitHub Release 为准。

## 0.1.63 · 2026-10-25

- Claude、Grok、DeepSeek API Key 账号支持 LM Detector 手动检测、定时检测、降智标记和复查；启用前为账号选择有效模型。
- 分词器探测始终串行执行，数字采样保留并发选择；候选固定显示前五名，分数三位、置信度两位小数，缺失值显示“—”。
- 按实际转发型号严格比较 Claude、GPT、Grok 和 DeepSeek 的家族、档位及版本；未知别名和不可比较型号显示无法判断。
- LM Detector 支持重试明确失败的组，保留成功样本和原检测库版本；补齐后继续原先选定的分词器探测。
- 修复持续预约提交时的 422，沿用周期重置后 3 秒执行、后续续约及停止规则。
- 官方提前释放额度后清除旧周期冷却和恢复等待；账号已解除限制时移除旧任务，仍受限时使用新周期证据进入恢复验证。
- 兼容仅含 OpenAI 的旧检测配置；新增平台默认关闭定时检测、采样一组，平台设置分别保存。

## 0.1.62 · 2026-10-25

- 模型测试新增 LM Detector，支持 1／3 组采样、候选排名、各组预测与可选分词器探测；未校准置信度明确显示为空。
- OpenAI 定时检测及降智复查可选择检测源，三组等待完整有效结果；跨家族证据和无法判断原因进入日志，其他自动触发保留 ModelTrace。
- 配套检测库支持手动更新及校验，任务保留创建时的源、组数和版本；分词器失败或停止保留数字结果。
- 手动偏好按连接与账号保存，调整桌面、窄窗口和手机的表单、候选列表及底部操作区。

## 0.1.61 · 2026-10-25

- 配置页过滤不可编辑、保留、失效及环境变量覆盖项，搜索与分组计数同步收窄。
- 预约测试接受后立即关闭弹窗；失败或需确认时显示原因并保留输入。
- OpenAI OAuth 账号新增持续周期预约，重置后 3 秒执行，7d 满额且有效上游 429 时自动停止。
- 连续预约沿用启用时的模型及现有持久化队列；支持停止后续预约、重启恢复与逐轮历史，未知结果不自动重放。
