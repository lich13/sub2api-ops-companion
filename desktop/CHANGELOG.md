# Sub2Ops 发布记录

这里记录公开版本的主要变化。每个版本按“新增、改进、修复、兼容”说明实际影响；构建包和校验值以对应 GitHub Release 为准。

## 0.1.31 · 2026-10-08

- 修复 WS 上游限流未写入错误表时漏用卡的问题：结合当前有效的账号限流状态与同窗口 7d 原始用量判断，并在消费前再次核对；明确的本地或客户端限流不作为用卡依据。
- 用卡成功、按所选方式验证通过且调度恢复确认后，合并发送一条“✅ OAuth 用卡成功，已恢复调度”Bark 通知；结果不确定不报成功，通知重试不重复用卡或测活。
- 所有账号模板统一支持改名、编辑、独立保存和删除；原三套模板保留内容与顺序，删除后不会重建，允许清空全部模板。保存、删除使用带无障碍标签的图标按钮。
- 账号列表支持勾选多个账号应用指定模板，先逐项预览，再持久化整批任务。忙碌账号独立排队，成功项不回滚，冲突项重新预览；操作待办可查看完整批次。
- WS、SSE 及非流式记录缺少首字时间时，TPS 统一按输出 Token 除以总耗时计算；首字继续显示“—”，不参与慢首字判断。
- 保留额度查询预算、自动模型检测冷却、恢复选择、历史及有效配置；仅局部更新账号模型配置，不修改 Sub2API 源码、镜像或表结构。
- 安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.30 · 2026-10-08

- 新增按账号选择连接测试或一组模型测试的 OAuth 恢复验证；自动用卡跟随选择，在确认重置成功后立即验证。
- 降智错误和慢首字预警改为检测线索，不再直接推送。确认首组指纹命中降智模型、保存标记并核实停调度后，才发送 Bark 处置结果。
- 所有自动模型测试共用每账号五分钟门限；冷却中的线索直接忽略，定时与恢复任务等待，手动测试保持原规则。预算和处置通知跨重启保留。
- Key 回退新增“OAuth 可用时也启用”，支持 OAuth 与指定目标 Key 共存；未知状态不改变调度，人工控制和降智暂停优先。
- 事件页分为降智错误、其他错误和恢复历史；分类独立分页，本地限流继续排除，未关联及已删除实体的其他错误可查。
- 隐藏已经终止的用卡和人工处理状态，保留消费证据；不确定的重置继续显示待确认。配置与旧接口兼容，保留现有紧凑布局及历史数据。
- 安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.29 · 2026-10-07

- 账号操作区恢复紧凑的单列按钮，统一字号、行高、图标尺寸和文字位置；操作列缩窄，调度开关与表头对齐。
- “更多”菜单改为独立浮层，完整显示测试连接、恢复状态、应用模板和删除入口，不再被下一行或表格滚动容器遮挡；靠近窗口底部时向上展开。
- 菜单支持方向键、Home／End、Escape 和点击外部关闭；滚动表格时关闭，避免浮层留在错误位置。
- 分组账号的名称、ID、类型和状态统一左对齐，长名称自然换行，保留拖放、点选和分组草稿。
- 保留 0.1.28 的连接兼容、自定义模板、模型测试、最近调用排序及 Android 发布页更新行为；不改变后台自动化或账号数据。

## 0.1.28 · 2026-10-07

- 修复调度操作与快照读取的锁顺序冲突，避免后台检测被阻塞后整个服务持续超时；进行中的旧快照不再覆盖缓存失效标记。
- 新增自定义账号模板，支持新增、重命名、编辑、删除及单账号应用；内置模板、旧版本配置和局部字段写入语义保持兼容。
- 改进 Sub2API 0.2.14 连接诊断与端点选择，网络或路径失败可回退已配置端点，鉴权拒绝和协议错误明确展示；离线保留旧快照。
- 修复模型测试弹层的控件、进度、结果和指纹库布局，以及账号操作列挤压、错位问题；默认按最近调用时间排序。
- Android 检查更新改为打开稳定 Release 页面，macOS 继续打开 DMG；仅允许本仓库的合法版本地址。
- 合并云端运维工具迁移，devhost 环境工具与 CI 由独立运维仓库维护；保留全部业务功能与用户数据。
- 安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.27 · 2026-10-06

- 新增 OpenAI OAuth／Key 账号的定时模型检测，默认关闭、间隔 15 分钟；新容量错误或慢首字预警可独立触发检测。
- 自动检测首组有效指纹命中 `gpt-5.6-luna` 时立即标记并停调度，分别核对两项结果。手动测试不执行自动处置，人工操作始终优先。
- 账号页新增三套手动模板：满血、降智、降智接管；移除旧模板的标记联动与按标记批量应用。
- 完善指纹库官方备用读取、限流与失败冷却、结构和哈希校验、版本固定及更新状态展示；内置库与一／二／三组参考评分已对照验证。
- 保留既有配置、额度预算、用卡状态、Bark 队列及历史数据；不修改 Sub2API 源码或表结构。

## 0.1.26 · 2026-10-02

- 新增 OpenAI OAuth 与 API Key 的慢首字预警：最近 24 小时 10 条有效文本流式调用中，至少 8 条首字超过 10 秒时发送一次 Bark 重要提醒。
- 统一排除有明确证据的 Companion 本地限流 429；真实上游容量错误、并发限流和历史记录继续保留。

## 0.1.25 · 2026-10-02
