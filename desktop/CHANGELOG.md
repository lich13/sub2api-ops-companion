# Sub2Ops 发布记录

这里记录公开版本的主要变化。每个版本按“新增、改进、修复、兼容”说明实际影响；构建包和校验值以对应 GitHub Release 为准。

## 0.1.48 · 2026-10-21

- 移除账号质量评分的计算、缓存、API 及所有界面入口，保留代理质量检测、慢首字线索和降智标记；主窗口默认宽度改为 1310。
- 新增“事件 → 日志”，展示已创建自动检测任务的正常、降智、失败、取消、中断、待确认和恢复结果；支持分页及指定任务详情，通知与实际处置分别显示。
- 自动检测模型在功能页全局配置，默认 `gpt-6-luna`。旧每账号模型不再作用于新任务，修改配置不改变已有任务或重复执行恢复验证。
- 修复候选被 Sub2API 管理目录的模型映射或本地默认列表替代的问题，直接读取当前账号供应商原始目录，保留凭据、代理、缓存及资格保护。
- 历史任务保留精简结果摘要，清理过的旧报告明确显示详情不可用；浏览日志不触发模型请求或 Bark。
- 不改变数据库结构和状态版本号；新增字段可选，保留 0.1.47 回退兼容。提供 DMG、签名 ARM64 APK 和 SHA256SUMS。

## 0.1.47 · 2026-10-19

- 模型测试和定时检测统一使用当前账号上游目录中的文本模型，不再由分组白名单替代目录，也不补入其他账号或父账号白名单模型。
- 列表、提交、派发和恢复复查使用同一候选规则；已保存模型缺失时保留原值并提示，不自动替换。
- 账号目录使用有界内存缓存：60 秒内复用，短时故障最多沿用五分钟成功结果；目录读取失败不会被当作模型已移除，连接和账号配置变化会隔离旧结果。
- 相关客户端请求统一为 20 秒，保留设置草稿，忽略关闭或连接切换后的迟到结果；不自动重发写操作。
- 显式处理操作批次引用和代理质量数组的异常结构，保留原有 503／502、幂等、取消及损坏状态保护。
- 不迁移业务状态或数据库，不改变降智判定、保活和连接测活；提供 DMG、签名 ARM64 APK 与 SHA256SUMS。

## 0.1.46 · 2026-10-16

- 新增按账号独立的保活开关，覆盖全部平台和类型，默认关闭；沿用现有账号操作入口及离线、只读和版本冲突保护。
- 每两秒检查原生临时错误暂停，保留人工调度、额度阈值、认证、限流、降智和活跃任务边界；使用上游原生接口并读回确认，原生接口同时清除模型级限制。
- 保活至少间隔 60 秒、一小时最多五次；第五次确认后自动暂停并通过既有 Bark 配置通知。重新开启不清空记录，未知请求仅核对、不自动重发。
- 修复极端指纹参数引发数值溢出后的 ModelTrace panic；异常数据返回明确错误，正常模型排序和降智规则不变。
- 增加异常结构、账号互斥、保活持久化及界面回归，稳定目录测试的同步等待；启动日志仅输出脱敏监听范围与端口。
- 原生安装包移除携带构建机路径的调试信息，并增加 Mac 与 Android 成品路径检查，保留签名与下载校验。
- 保留配置、Keychain、业务历史及数据库结构，新增独立 0600 保活状态文件；提供 DMG、签名 ARM64 APK 与 SHA256SUMS。

- 集中有效报告与指纹库检查，异常快照安全返回；统一测活默认值并保持原配置和默认模型。
- 上游诊断落盘前脱敏，审计入口递归保护凭据与请求正文；保留正常字段、数值类型、权限及审计失败语义。
- 补齐路由鉴权、目录代理请求头过滤及模型处置回归；整理长语句，明确直接运行的监听范围和跨主机数据库 TLS 要求。
- 升级保留配置、Keychain、业务状态和历史，提供 DMG、签名 ARM64 APK 与 SHA256SUMS。

## 0.1.43 · 2026-10-16

- 状态、配置、审计及文件锁在写入或取得锁后收敛为 `0600`；保留原子替换、只读检查与现有状态格式。
- Bark HTTPS 校验拒绝非公网字面 IP 及映射写法；保留官方、公网自建和既有 HTTP loopback 场景，不改变通知重试规则。
- 修正 Android 平台声明，明确反代前缀语义；显式处理 OAuth 非法键，固定请求与响应各自的大小边界。
- 统一 Python 对照来源和工具链文档，固定现有前端依赖解析版本；CI 增加并发控制、必要超时与缓存，保留全部检查及依赖审计。
- 升级保留配置、Keychain 和业务历史，提供 DMG、签名 ARM64 APK 与 SHA256SUMS。

## 0.1.42 · 2026-10-15

- 关键后台任务异常统一停止新派发并有界收尾、非零退出，避免轮询或推送静默停止；普通业务错误、重试和 HTTP 异常响应保持原样。
- 补齐操作队列与模型测试的异常清理，释放锁、许可和任务登记；未知结果禁止重放，保留现有重启核对流程。
- 每日调度沿用注入时钟；状态和配置新增脱敏启动诊断，新文件 `0600`、已有权限保持不变，不改 JSON 格式或数据库结构。
- 固定构建依赖来源，加入两份 Cargo 依赖审计、只读健康检查与版本一致性校验；修复 Rustls 漏洞并移除未使用的 MySQL/RSA 依赖链。
- 机制与升级说明分离，保留迁移命令和隔离 Python 测试驱动；安装包仍为 DMG、签名 ARM64 APK 和 SHA256SUMS。

## 0.1.38 · 2026-10-13

- 自动用卡前置可信卡余额门禁；零卡、全部过期、未知或无效观测直接跳过，不建任务、不补查、不暂停、不占预算，也不产生未执行结果通知。
- 后续确认有卡仍沿用原耗尽事件的五分钟窗口；重复限流、余额变化和重启不延长期限。消费前复核余额，消费后归零不影响验证、恢复及未知回执核对。
- 升级收束尚未消费的旧零卡／未知余额任务，取消未发送的无意义通知；保留消费、预算及历史，撤销临时暂停前继续核对归属与人工控制。
- 代理、模板、删除所选和分组草稿使用 Sub2API 原生批量接口；每次最多 100 个账号，分组按完整目标集合归并，保留范围之外的归属。
- 前端一次提交整批意图，服务端持久化后执行。忙碌、冲突及部分失败分别处理；派发分块和逐项结果可追踪，超时、断线和重启先读回，不整批重放。
- 原生路由明确不支持时显示兼容执行，鉴权或业务错误不触发回退重放。保留删除确认、代理继承、模板局部写入、连接隔离和紧凑界面。
- 定时检测继续要求调度开启。保留配置、Keychain、检测冷却、预算、通知及恢复历史；安装包提供 DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.37 · 2026-10-12

- 账号、分组、安卓及批量操作补齐语义图标，统一图标槽、文字对齐和加载状态，保留紧凑布局与危险操作确认。
- 单账号和批量代理选择接入 Sub2API 原生连接与质量检测，就地展示延迟、出口、评分、等级及目标状态。检测不选择或应用代理，同类请求合并，不自动重试。
- 自动用卡限定在本轮原始耗尽事件后的五分钟内派发；迟到日志、重复限流、补查和重启不延长期限。过期、无卡、预算不足或资格变化时结束，不再长期等待。
- 缺少可信卡证据时最多补查一次；本轮唯一消费豁免一小时查询间隔，但补查和消费仍受滚动 24 小时六次预算约束，普通查询规则不变。
- 用卡成功后五分钟内最多两轮恢复验证，可重试失败至少间隔一分钟，模型验证保留五分钟冷却。未知消费禁止重放，验证未完成时保留必要暂停。
- 每轮结束后独立通知实际结果；用卡与降智处置合并通知，只有三项均确认成功才记录用卡恢复。Bark 最多五次投递，失败不重跑业务操作。
- 修复补查后消费被查询冷却阻挡，以及暂停保存失败导致尚未派发的消费被误报为不确定的问题；重启和迟到结果不能覆盖人工控制。
- 定时检测仅在账号允许调度时生效，包括降智账号。关闭后保留设置，重新开启后重新计时，旧结果不得取消标记或补跑错过周期。
- 升级保留预算、冷却、历史及去重，收束旧的超时活动任务，旧已结束历史不补发。安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.36 · 2026-10-12

- 桌面账号表铺满可用宽度，操作区展开全部适用按钮并随窗口宽度自动换行；保留账号名称列折叠、紧凑字号与统一图标对齐。分组及安卓继续使用菜单。
- 批量操作栏新增“选择代理”，可为多个账号设置同一个代理或清除代理。提交前逐项预览当前与目标、无变化项及继承限制，提交后分别显示排队、成功、冲突或失败。
- 批量代理请求先完整持久化，再进入账号操作队列；按代理字段版本核对，只写入代理字段。成功项不回滚，超时先核对实际值，重启不盲目重放未知写入。
- 恢复监控每两秒读取已选账号的最小状态，准确恢复时间不再统一追加 60 秒；多个必要阻断仍取最晚时间，估算时间保留安全余量。
- 账号独立完成额度核对和验证，不再等待整批查询；Bark 投递独立运行。优先复用跨恢复点的有效额度，查询预算、模型验证五分钟冷却、并发及账号互斥保持有效。
- 等待状态区分恢复时间、额度证据、查询预算、查询或模型冷却、执行槽及账号忙碌。恢复方式或人工控制变化后，旧结果不能覆盖新设置。
- 验证回执先保存再推进恢复；提交失败或重启后先核对账号实际状态，缺失可靠回执时保留待确认，避免重复测试。保留用卡消费记录、去重、恢复历史及通知队列。
- 保留有效配置、Keychain、模板、分组草稿及自动化状态，不修改 Sub2API 源码、镜像或表结构。安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.35 · 2026-10-11

- 新增单账号模型白名单、模型映射和代理编辑，账号页与分组共用入口。支持同步上游模型目录后搜索、勾选加入草稿并明确保存；不修改模板或分组白名单。
- 优先级、并发和负载因子集中为“调度参数”，使用固定宽度浮层输入，支持增减、Enter 保存、Escape 取消及负载因子自动模式；修复数字被保存按钮挤压的问题。
- 桌面账号列支持紧凑折叠与展开，保留本地偏好、完整名称提示及真实 ID；账号和记录布局统一收紧，保留安卓触控尺寸、记录自动加载和精确汇总。
- 质量查询只读取所需字段，去掉整行 JSON 转换，兼容可选字段缺失。成功率、首字、输出 TPS 分别取样，缺首字不再丢弃整条调用；TPS 与记录页统一使用总耗时。
- 质量详情展示各维度样本数及缺项原因，区分调用不足、首字未记录、暂无可比基准和统计更新失败；临时失败保留旧明细与真实计算时间，不伪造最新评分。
- 编辑按字段校验版本并复用操作队列，模型配置和代理仅局部写入。普通调度参数变化正确衔接恢复与用卡任务，保留人工控制及凭据变更保护。
- 保留配置、Keychain、账号模板、分组草稿、额度预算、自动用卡、自动检测、历史及通知队列，不修改 Sub2API 源码、镜像或表结构。
- 安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。

## 0.1.34 · 2026-10-10

- 新增降智账号定时复查：有效检测确认恢复正常后取消标记并发送 Bark，保持当前调度状态。人工关闭、认证异常及真实额度阻断仍优先；失败或分析不足不清除标记。
- 修复 Codex 百分比满额但仍有可用点数时误暂停自动检测的问题，兼容原生点数快照、隐藏余额与秒级时间。点数未知且没有当前阻断时继续按计划检测，不增加额度查询。
- 误暂停的已开启任务重新计时，不补跑遗漏周期。保留五分钟门限、共享凭据互斥和人工操作优先；取消标记、通知投递分别核对并持久化。
- 记录页改为滚动接近底部自动加载，保留筛选、消费汇总和滚动位置；失败就地重试，后台、离页和弹层期间暂停续读，旧连接响应不回写。
- 输出 TPS 对齐 Sub2API 原生规则，统一使用输出 Token 除以总耗时并显示一位小数；删除旧的减首字算法，缺失首字仍显示“—”。
- 仅将升级后新增的合资格 OAuth 母账号自动加入“测试连接”，保留已有选择、人工取消和模型测试分类；分类变更不触发调度、额度查询或测活。
- 修复单并发模型测试的提前完成派发竞态，以及失败组重试时第 1 组证据与汇总结果混用的问题；手动测试仍无自动处置副作用。
- 保留账号模板、配置、Keychain、自动用卡、预算、恢复历史及通知队列，不修改 Sub2API 源码、镜像或表结构。安装包提供 Mac DMG、签名 ARM64 APK 和 SHA256SUMS，不发布 ZIP。
