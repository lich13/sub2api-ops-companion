# Sub2Ops 0.1.109

- 修复 Android 应用内更新下载连接后被误判为已取消的问题（修正 `watch` 通道无初始接收方时序号未写入的缺陷，补齐端到端下载、SHA-256 校验与安装器调起测试）；该修复自 0.1.109 起对后续版本更新生效，当前已安装 0.1.108 的 Android 设备需手动覆盖安装一次 0.1.109 APK。
- 修复跨端多实例切换与状态竞态：macOS 客户端按连接隔离账号批量选取、测试横幅、恢复忙碌锁、用量刷新进度与使用记录游标，修复操作清单与批次详情轮询互相覆盖、关窗后测试弹窗残留轮询、「最高用量」排序未使用原生合并峰值、优先级拖放未校验锁定账号位移与编辑态、Sub2API 配置确认窗未遮蔽敏感值及跨实例迟到回执误关确认窗；Web / Android 客户端修复懒加载组件预载后重挂清空弹窗草稿与重进 Sub2API 配置页不重查宿主操作状态的问题，并提升 macOS 搜索框占位符与警告色深浅色对比度及清空按钮热区。
- 服务端状态竞态修复与稳态资源优化：修复模型检测锁内二次校验遇 5xx 误取消活跃任务、操作终态回执落盘失败卡在 `running`、OAuth 配置双快照校验竞态及批量额度刷新父账号变更锁重算；将模型检测逐分钟频率取样闸门移至内存（稳态仅 `recent_request_count` 变化时落盘）、容量告警前向分页拆出轻量游标路径并为慢首字查询增加失败退避、操作终态事件缓冲改按到期时间休眠、软删账号对账改按本地候选集精确过滤、SSE 流扫描跨分片续接且先验上限、ModelTrace 内置指纹库改按需延迟编译，并并行化 CI macOS 检查与移动端响应式回归。
- 请先升级 Companion 与配置宿主，再更新 macOS 和 Android 客户端；HTTP 接口、业务数据库结构与服务端 JSON 状态格式均保持不变，回退 0.1.108 可直接使用 `rollback-0.1.108` 镜像与现有数据（详见 `UPGRADING.md`）。
