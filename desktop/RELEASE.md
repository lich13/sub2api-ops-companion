# Sub2Ops 0.1.106

- Android 客户端支持内置一键检查、下载与安装更新：在应用内直接检测稳定版、流式下载 ARM64 APK 并展示实时字节进度与取消入口，强制校验字节大小、SHA-256 摘要、包名与版本号后通过 `FileProvider` 调起系统安装器；未开启「允许安装未知应用」权限时自动引导授权并在返回应用后无缝续装，同时在未连接、离线或等待快照兜底页保留客户端自更新入口，无需再跳转外部 GitHub 页面。
- 全链路响应速度优化：服务端 `/snapshot` 并行读取顶层查询、流式直写 SHA-256 计算版本摘要、消除单行重复 `to_jsonb` 物化并支持弱 `ETag`（`304 Not Modified` + `x-observed-at`），配合双端 `ObservedClock` / `ops-observed` 细粒度时间订阅与托盘提示去重，静息轮询实现零响应体传输、零整包 JSON 重解析与零全树重渲染；使用记录只读事务握手由 3 次往返合并为 1 次，账号锁与测试队列改为事件唤醒加 35ms 起步自适应退避轮询，双端批量添加代理改为 5 路限流并发，Android 首屏按需拆包并将记录样式下沉至懒加载分片。
- 数据一致性与历史包袱深度清理：修复 macOS 原生用量读取缺少版本键失效、覆盖今日统计及失败后每 2 秒无限重试的问题，按单账号槽位隔离观察粒度；补齐模型测试与代理保存的明确错误反馈，清理伪必填类型契约、无生产调用的死接口、防重构字面量锁死测试及重复覆写的移动端样式规则。
- 请先升级 Companion 与配置宿主，再更新 macOS 和 Android 客户端；沿用现有 HTTP 接口、业务数据库与运行状态格式，回退 0.1.105 可直接使用保留镜像与当前数据。
