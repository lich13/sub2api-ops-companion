Sub2Ops 0.1.16 修复快捷面板分组账号错配并按最近调用排序。

- 快捷面板与分组动态只显示当前仍属于该分组的账号；移出分组的历史调用不再影响排序。
- 分组按最近一次有效调用时间排列，未调用分组置底，同一时间按分组 ID 稳定排序。
- 移除分组收藏入口，保留快捷面板固定功能和旧偏好兼容。
- 保留自动用卡、即时测活、额度限频、Bark、Key 回退、现有配置和 Keychain。仅修改 Companion。

系统要求：macOS 12+ / Apple Silicon，或 Android 12+ / ARM64。提供 DMG、固定签名 APK 和 SHA256SUMS，不提供 ZIP。
