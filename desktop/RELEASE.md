# Sub2Ops 0.1.49

记录页新增请求类型与压缩徽章，收紧列表和详情排版，并在本机记住最后一次账号排序。

## 记录与账号界面

- 记录表、移动端卡片和详情使用相同的类型徽章：同步、流式、WebSocket、安全策略、Live、未知。压缩标记独立显示，可与同步或流式并排。
- 新默认列包含“类型”，位于模型之后。已有自定义列和空选择保持不变，可从列菜单开启。
- 记录表、筛选控件和详情间距收紧，多行内容自然撑高；移动端继续保留至少 48px 的控件触控高度。
- 账号页排序、测活结果、账号模板和筛选控件的文字统一为 12px。本机保存最后选择的排序字段与方向，跨连接及重启沿用，首次按最近调用倒序；筛选条件不保存。
- 定时检测弹窗删除检测模型行，功能页删除自动检测模型输入下方的说明。全局模型输入、草稿及必要告警保留，自动检测、恢复、保活、Bark 和代理检测机制保持现有行为。

## 升级与安装

- 显示真实压缩标记需要 Sub2API 包含 migration 231。没有压缩列或连接旧 Companion 时不显示压缩标记，普通记录仍可查看；查询故障正常报错。
- 不新增数据库迁移，不改变业务状态版本。保留配置、Keychain、历史及 0.1.48 回退兼容；回退旧客户端后其旧规则可能移除“类型”列偏好。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS，不提供 ZIP。
