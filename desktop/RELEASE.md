# Sub2Ops 0.1.76

- LM Detector 检测库升级到上游 `fd9b4caf`，分析器标识更新为 `lmfpd-0.2.0`；保留现有离线评分与请求控制，上游 SDK 不兼容时保留当前检测库并提示升级服务端。
- 提前重置检测优先验证现有代表，仅在失效时按耗尽优先、账号 ID 次序重新选择，减少重复计算；检测间隔、人工操作保护及普通查询预算保持不变。
- 构建时校验完整检测库并生成评分所需的精简元数据，减少内置数据体积和加载开销；完整原库继续保留用于溯源与参考对照。
- 启动时校验新内置库后迁移已知旧内置版本，清除旧更新错误；保留旧缓存、历史和固定版本任务，其他远程版本不自动覆盖。
- 检查更新时，兼容性校验通过且三份数据均未变化则只记录检查结果，跳过下载和新增缓存目录；数据变化仍完整校验后切换。
- 当前缓存读取失败时仍可下载并校验新的上游版本，保留通过更新恢复检测库的能力。
- 补齐回退到 0.1.75 时的检测库校验和版本指针恢复步骤，保留当前业务状态和历史记录。
- 修复浏览器存储访问受限时账号操作在发送请求前失败的问题，继续使用内存中的稳定客户端标识。
