# Sub2Ops 0.1.103

- 修复 macOS 原生客户端用量窗口「今日请求数」将整数显示为 6 位小数（`2.000000 req` → `2 req`）及千分位进位跳变（`999.9K → 1.0M`、`999.9M → 1.0B`）的问题，补齐零费用场景下的今日 Token 用量展示。
- 修复 macOS 原生客户端「Sub2API 配置」切换标签页或连接时覆盖远端修订号、读取失败未锁定只读、提交异常未保护本地草稿及轮询自取消竞态；修复「模型测试」策略未就绪可点击测试、重试期间停止按钮禁用与「优先级」任务短暂断线后轮询停滞的问题，补齐授权链接、任务取消和素材读取的错误提示。
- 统一双端 `sub2ops-protocol` 账号模板、余额刷新、模型策略与账号创建等协议结构及记录列白名单，合并服务端重复的模型版本比较与降智等级逻辑，清理服务端未读配置字段、废弃旧入口与 Android 前端残留的桌面无效样式及偏好参数，抽取服务端集成测试共享底座，并更新前端依赖 `@tybys/wasm-util` 至 `0.10.5`。
- 请先升级 Companion 与配置宿主，再更新 macOS 和 Android 客户端；沿用现有 HTTP 接口、业务数据库与运行状态格式，回退 0.1.102 可直接使用保留镜像与当前数据。
