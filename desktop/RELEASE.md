# Sub2Ops 0.1.62

模型测试新增 LM Detector，支持 1／3 组采样、候选排名及各组预测；单组显示初步结果，未提供置信度时显示“—”。可选分词器探测，独立展示候选、一致性与请求状态。

OpenAI OAuth／Key 的定时检测及降智复查可选择检测源和组数。LM Detector 按 Claude、Codex、Grok、DeepSeek 的业务等级判断；三组等待完整有效结果，无法判断时保留原标记和调度。慢首字、报错、额度恢复及用卡验证继续使用 ModelTrace。

LM Detector 检测库支持手动更新，配套资源校验后整体启用，已有任务保留原版本。检测日志补充来源、版本、采样和处置依据。按连接与账号记住手动选择，分词器探测每次默认关闭。
