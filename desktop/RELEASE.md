# Sub2Ops 0.1.47

模型测试与定时检测现在只使用当前账号上游目录返回的文本模型，列表和实际提交采用同一规则。分组白名单、父账号白名单及其他账号目录不再额外补入模型；已有模型选择保留，缺失时明确提示，不自动换模型。

## 目录与可靠性

- 当前账号目录在 60 秒内复用；按需刷新期间可沿用未满五分钟的成功结果。读取失败不视为模型已移除，成功空列表会清除旧候选。
- 每个账号只保留一次在途刷新，服务最多同时刷新八个账号；请求、内存和关闭流程均有上限。连接、凭据或相关账号配置变化后不会串用旧结果。
- 模型目录、测试提交和定时检测保存使用 20 秒客户端超时；失败保留设置草稿，关闭或切换连接后忽略迟到响应，不自动重发写操作。
- 操作批次引用和代理质量结果改为显式校验；保持既有错误码、幂等、取消与状态保护。

## 升级与安装

- 不改变 HTTP 路径、模型数组格式、JSON 状态或数据库结构；模型目录缓存仅在内存中，服务重启后按需重新读取。
- 降智判定、标记、调度、复查条件、Bark、保活及普通连接测活行为保持原样。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS，不提供 ZIP。升级保留配置、Keychain 和业务历史，可使用当前兼容状态回退到 0.1.46。
