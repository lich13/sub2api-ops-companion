# Sub2Ops 0.1.81

- 修复 Sub2API 升级后配置字段消失：内置目录同步至 0.2.19，版本和提交差异改为提示；新增 Gemini 同账号重试次数，默认 4，范围 0–10。保留环境覆盖、草稿冲突检查和应用失败回滚。
- 合并用卡请求、成功释放及暂停期间改参的重复账号读取与状态保存，保留归属核对和写后确认；扣卡后读取失败仍保存已知结果，未知扣卡不重放。
- 精简恢复意图专用回执、时钟门禁和解除暂停标记；中断验证沿用重试，模型等待复用原任务并保留历史关联。
- 停止已结束用卡任务的重复 worker 派发；旧排序仅启动时收束，已完成迁移和从未创建的状态文件直接返回。
- 重启后隐藏缺少重试上下文的按钮，保留检测结果；检测日志每页只扫描一次恢复历史。
- 审计日志保留当前及上一份，每份最多 20 MiB；轮转保留写入锁，读取覆盖两份并继续脱敏。
- HTTP 响应结构、状态文件版本、手动模型请求校验及临时数据库错误处理保持兼容。
