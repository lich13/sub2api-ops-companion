# Sub2Ops 0.1.42

本版整理 Rust 服务的后台异常收尾、状态诊断与构建验证，保留现有界面、接口、配置、调度和恢复规则。

## 服务可靠性

- 关键后台任务 panic 后统一停止接受和派发新任务，在 60 秒内收尾并非零退出，由现有容器重启策略恢复；普通业务错误继续使用原有重试与退避。
- 操作队列和模型测试在异常或取消后释放任务登记、账号锁及并发许可。已派发的未知结果保留核对状态，不自动重复测活、用卡或不可逆写入。
- 每日调度使用统一时钟，保留北京时间日期去重和重启持久化。
- 新状态文件默认 `0600`，已有文件保留权限；启动诊断只报告资源类别和固定错误码，不暴露文件路径或密钥。可选 Bark 配置无效时保持原有处理方式。

## 构建与部署

- GitHub Actions 和基础镜像固定到提交或 digest；两份 Rust 锁文件增加依赖审计，更新 Rustls 安全补丁并移除未使用的 MySQL/RSA 锁文件依赖。
- Compose 增加只读健康检查，保留非 root 运行、回环端口及现有重启策略；unhealthy 本身不会另行触发重启。
- 发布版本以服务端清单为准，CI 校验客户端、锁文件、镜像和文档一致；模型转发已核对的 Sub2API 版本集合保持不变。
- 机制与历史迁移说明移入 `docs/` 和 `UPGRADING.md`；保留 Python 测试依赖及旧配置迁移命令。

## 安装包

- macOS Apple Silicon：DMG（macOS 12+）。
- Android ARM64：签名 APK（Android 12+）。
- SHA256SUMS：安装包校验文件；不提供 ZIP。

升级保留配置、Keychain、业务状态和历史，沿用当前状态支持回退。
