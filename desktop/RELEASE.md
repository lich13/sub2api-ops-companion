# Sub2Ops 0.1.79

- 活动恢复任务在额度查询失败或额度暂不可复用时继续保留，网络错误、额度不完整与认证失效进入原有记录、退避和告警流程。
- 人工操作记录当时的额度或阈值窗口，后续周期按各窗口识别；同周期刷新与截止纠偏不会复活已取消任务，历史记录沿用已有证据。
- 手动刷新与后台复核统一判断额度释放，新鲜完整额度确认释放后进入所选验证流程，不再因旧限流截止时间的精度差异延迟恢复。
- 验证中任务在运行时保留 testing 状态，仅在启动恢复时处理遗留中断；继续核对已有派发标记与回执。
- LM Detector 单样本复用汇总判定并减少样本复制，多样本独立判定、首组重试与最终汇总保持原语义。
- 恢复执行槽排队按轮合并保存，等待不变时跳过重复写入，界面保持“等待恢复执行槽”，空闲后由现有调度派发。
- 模型排队、冷却和等待结果继续复用额度证据及已有模型任务；真实失败仍要求相应证据，保留原有退避与次数限制。
- 可重试请求失败时一次保存错误、诊断与重试或失败状态，减少完整模型历史写入；HTTP 接口、客户端字段和状态文件版本兼容。
