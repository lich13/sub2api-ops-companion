# Sub2Ops 0.1.29

本版本修复账号操作区和分组管理的对齐问题，恢复紧凑的桌面按钮，并让“更多”菜单完整显示。

## 改进

- 账号操作区恢复单列小按钮，统一字体、行高、图标和间距，减少占用宽度。
- “允许调度”与“操作”的表头、开关和按钮按列对齐；排序控件与账号模板入口保持相同高度。
- 分组条目的名称、ID、账号类型与状态统一左对齐，长名称自动换行；安卓继续使用纵向卡片及触控尺寸。

## 修复

- “更多”菜单使用独立浮层，修复被下一行账号或表格边界遮住的问题。靠近窗口底部时自动向上展开。
- 菜单支持方向键、Home／End、Escape 和外部点击；页面滚动时自动关闭，选择操作后正常打开对应面板。

## 兼容

- 保留 0.1.28 的 Sub2API 0.2.14 兼容、连接诊断、自定义账号模板、模型测试布局与最近调用排序。
- 仅调整 Companion 界面，不修改账号、分组、模型配置、调度、额度预算或后台自动化；配置及 Keychain 保持兼容。

## 安装包

- macOS Apple Silicon：DMG（macOS 12+）。
- Android ARM64：签名 APK（Android 12+）。
- SHA256SUMS：安装包校验文件；不提供 ZIP。
