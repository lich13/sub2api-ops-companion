# Sub2Ops 0.1.100

- macOS 配置编辑保留结构化 YAML 中的数字、布尔值、空值和带特殊字符的键。嵌套映射出现重复键时会指出错误，原文件保留。
- 修复刷新模型目录和切换连接时的旧结果处理。账号授权失效后移除旧模型，临时网络错误仍可重试。Mac 进入后台会取消正在读取的使用记录。
- 客户端和服务端共用 API 契约。账号令牌、代理凭据等只由对应接口返回，模型检测配置缺少必要字段时提示响应不兼容。
- 修复外部修改并发配置后后台任务沿用错误设置的问题。重启后按原记录核对已派发任务，控制文件损坏或丢失时保留现场并报告错误。
- 请在同一更新窗口先升级 Companion 与配置宿主，再升级 macOS 和 Android 客户端。0.1.99 客户端会拒绝新版优先级页响应。
