# Sub2Ops 0.1.53

修复批量测活结果收起，补齐全平台用量，增加费用明细，并统一 Sol 内部切换规则。

## 账号与用量

- 批量测试结果首次确认整批结束后，在固定 3 秒截止时间收起；刷新、失焦、切页不延长，挂起期间到期则恢复立即隐藏。移除“测活结果”独立按钮，保留运行进度、停止、关闭和提交恢复。
- 普通 Key、upstream、Bedrock 显示今日请求、Token、账号费用、用户费用及已配置额度；原生平台显示适用滚动窗口、模型配额或多币种余额。
- 区分零用量、过期数据、读取失败、授权缺失及未提供窗口；单账号读取失败不影响其他账号。用量记录费用支持悬停、聚焦和触屏点击查看明细，单价按记录费用及 Token 数计算。

## 模型检测

- 合法 Sol 模型之间任意版本切换均不判降智。跨档位、其他系列版本及 gpt-5.6-luna 强制规则保持原义。
- 已保存的历史结论不重算，不批量解除标记或恢复调度；后续复查使用新规则。

## 升级与安装

- 原生用量读取需要 0.1.53 服务端的只读 GET /api/desktop/v1/accounts/{id}/usage；新增字段可选，不改数据库结构及状态文件。
- 回退 0.1.52 使用当前状态及保留镜像，先停止新版写实例；旧版缺少新增用量读取并沿用旧判定规则。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS；覆盖安装保留配置和 Keychain。
