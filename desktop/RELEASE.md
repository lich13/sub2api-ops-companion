# Sub2Ops 0.1.75

- 修复 Android 冷启动、重新连接和返回前台后停留在“正在读取云端状态”的问题，桌面端继续保留隐藏窗口的节流优化。
- 在“功能 → 恢复与检测”加入独立的提前重置检测，默认关闭，检测间隔默认 60 秒、最小 2 秒。按 OpenAI OAuth 套餐选择代表账号，发现提前释放后逐账号刷新额度、测活、恢复并回读确认；保留人工停用、授权失效与其他处置持有的暂停。
- 提前检测不占用普通自动查询的一小时冷却和每日六次预算；在途批次合并，关闭后停止新派发，重启继续核对已有回执。
- 移除事件及导航入口的数字计数徽标，新增设置沿用统一字体和控件，手机单列布局。
- 复用未变化的已校验状态快照，按轮建立检测线索索引，操作列表只维护最近 30 条终态记录及全部在途任务，减少重复读取、排序和内存占用。
- 修复手动迁移旧配置时丢失现有重试、平台检测与恢复选择记录的问题；原生连接测试的错误响应增加 8 MiB 读取上限。
