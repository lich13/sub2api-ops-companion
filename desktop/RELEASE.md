# Sub2Ops 0.1.86

- 修复 7d 满额且遇到有效 429 时，旧卡观测阻止自动用卡的问题；按当前有效卡数判断资格，保留原有五分钟期限，不补扣已过期轮次。
- 修复关闭模型检测后，已有调度保持状态将“已关闭”覆盖成“已暂停”的问题；保留原有复查和外部恢复发现时机。
- 提前恢复、原生用量、模型用卡准备、模型重试和模板应用复用当前账号与证据，减少重复查询；等待锁或上游请求后的复核、可用卡次数检查及写后读回继续保留。
- 已结束用卡任务缺少恢复证据时跳过无用的耗尽查询，恢复后再次耗尽仍按原规则处理。持续预约统一使用完整账号投影，保留授权更新、套餐窗口和客户端查询合并。
- 删除无人使用的内部入口、旧结果标记和废弃消息表，精简无异步操作的函数；已有模板、保活、删除和恢复功能保持原有行为。
- 支持从 0.1.84 及以后版本升级，无数据库迁移，HTTP 接口和客户端功能保持兼容。回退保留当前数据与扣卡记录，不恢复旧状态快照。
