# Sub2Ops 0.1.108

- macOS 客户端彻底移除系统钥匙串依赖，解决本机签名应用每次覆盖升级因 `CDHash` 变化反复弹出钥匙串授权框的问题：各实例管理员 API Key 改为以 `0600` 权限原子写入 `~/Library/Application Support/com.lich13.sub2ops/credentials.json`（文件与父目录双 `sync_all` 加损坏/写失败保护），不读取旧钥匙串条目；升级后保留全部已保存实例列表，常用实例仅首次补输一次 API Key 即可在后续切换、重启与重装中永久免弹窗，Android 端保持现有零弹窗安全存储不变。
- 服务端 CPU、内存、磁盘 I/O、热 SQL 与并发治理：桌面账号快照与慢首字查询改用带可选列探测缓存与 `42703` 自动回退的标量投影，消除稳态每 1.5s–2s 的 `to_jsonb` 大字段 TOAST 解压；`/snapshot` 排除高频活跃时间字段的无效版本摘要重算，并将 JSON 序列化、SHA-256 与 Gzip 移出异步锁改为单飞 `spawn_blocking`；上游模型目录与测试 SSE 流改为有界增量流式解析，错误/通知与任务控制改为变化或关键生命周期节点持久化以降低磁盘 `fsync` 写放大，空闲后台循环改用 `Notify` 按需唤醒；编译期紧凑化 `sub2api-config` 目录并改为零克隆借用序列化，同时修复连接核验队列串行阻塞、代理池容量驱逐、恢复测活超时包装与关闭排空顺序。
- 双端客户端性能优化、草稿安全加固与历史包袱深度清理：Tauri 宿主稳态 `304 Not Modified` 改为零快照拷贝时间注入并剥离 macOS 端未使用的移动更新器模块；macOS 原生桥接复用线程编码器并经 `Data.withUnsafeBytes` 直传 FFI，共享 `AppStore.accountById` 字典、消除 `NumberFormatter` 分配、加固 Swift 6 WMO 受控输入、收口分组页 `NSMenu.popUp` 菜单禁用态与红色危险项并收敛 Toast 命中区；Android / Web 前端稳定操作回调保住卡片 `React.memo`、将优先级拖拽坐标改为 `ref` 直驱、配置 YAML 延后至失焦解析、静止与隐藏态挂起弹窗轮询，统一全量弹窗输入法 `Escape` 防护、遮罩防误关与脏草稿放弃确认，修复深色开关底色、分组动态加载图标与 `320px` 顶栏挤压，并深度清理跨端协议重复定义、透传碎片模块与 500+ 行冗余样式。
- 请先升级 Companion 与配置宿主，再更新 macOS 和 Android 客户端；沿用现有 HTTP 接口、业务数据库与服务端状态格式，macOS 升级后首次切换实例补输一次 API Key 即可永久零钥匙串弹窗，回退 0.1.107 详见 `UPGRADING.md`。
