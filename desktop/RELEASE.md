Sub2Ops 0.1.13 完善日期筛选、消费汇总与安卓布局。

- 记录默认今天，提供与 Sub2API 一致的八个日期预设及自定义日期；统一使用北京时间。
- 总消费按全部筛选记录的历史用户实扣汇总，支持查看、复制精确金额，不受分页影响。
- 安卓记录改为单列信息块，重排账号、事件、功能、设置与相关弹层，完整字段无需横向拖动。
- 保留历史模型路由、Token、首字/总耗时分色和 TPS；Mac 继续使用紧凑表格。
- 保留 OAuth 限频、Bark、自动化、配置和 Keychain；记录与汇总只读取已有业务数据。

系统要求：macOS 12+ / Apple Silicon，或 Android 12+ / ARM64。提供 DMG、固定签名 APK 和 SHA256SUMS，不提供 ZIP。
