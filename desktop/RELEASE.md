# Sub2Ops 0.1.85

- 修复更新授权后持续预约误报账号变化的问题，统一识别套餐窗口，免费套餐继续只按 7d 周期预约。
- 持续预约与客户端用量查询共享执行结果；内部刷新复用最新账号行，非 OpenAI 用量返回复用已计算统计，减少重复查询和投影。
- 精简用卡释放、普通恢复和提前恢复的重复读取；保留入口校验、等待与上游请求后的账号检查、成功启用后的最终确认及原截止时间，不重复扣卡。
- 用卡通知仅对到期重试或关闭后需停止的通知检查账号，保留退避、删除静默及扣卡回执。历史未超过上限时跳过保护集合收集，巡检直接借用共享任务。
- 删除旧用卡入口、无生产调用的缺字段补查及旧状态转换。支持从 0.1.84 及以后版本升级，HTTP 接口、客户端交互和当前状态格式保持兼容；回退保留当前数据与扣卡记录，不恢复旧状态快照。
