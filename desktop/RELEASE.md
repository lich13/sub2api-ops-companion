# Sub2Ops 0.1.43

本版加固敏感文件和 Bark 地址校验，整理构建与回归检查，并补充账号限流状态信息。

## 账号状态

- 桌面账号表和移动端账号块显示当前限流标签、自动解除倒计时及原因提示，悬浮保留准确解除时间。
- 当前仍限流、且最近错误后没有成功调用时显示 HTTP 429 入口，可打开已有错误详情。历史错误不会单独把账号标为受限。
- 倒计时到点显示等待状态刷新，不自行恢复调度或触发测活。

## 安全与兼容

- 状态、配置、审计与取得的文件锁统一收敛到 `0600`，不复制旧宽权限；原子替换、文件同步、状态格式及只读模式继续保留。
- Bark HTTPS 拒绝非公网字面 IP，保留官方、公网自建及既有 HTTP loopback 方式，不改变推送与重试语义。
- 平台声明补齐 Android；OAuth 非法键显式过滤；请求体和响应体保持各自现有大小上限。
- `BASE_PATH` 保留兼容读取，外部前缀仍由反向代理配置并剥离。

## 工程与安装

- 工具链文档与 CI 对齐；前端依赖固定为当前锁定版本，Python 对照提交改为单一来源。
- CI 增加并发取消、超时及 Rust／浏览器缓存，两个 Rust 锁文件仍每次执行依赖审计。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 及 SHA256SUMS，不提供 ZIP。

升级保留配置、Keychain、业务状态和历史；回退使用当前兼容状态。
