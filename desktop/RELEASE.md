# Sub2Ops 0.1.28

本版本改进 Sub2API 0.2.14 升级后的连接诊断，支持新增账号模板，并修复模型测试和账号操作区的布局。

## 新增

- 账号模板支持新增、重命名、编辑和删除自定义模板，最多保存 32 套。满血、降智、降智接管三个内置模板继续保留。
- 设置页新增连接诊断与重新检查，区分管理员 Key 被拒绝、上游不可达、管理路径不存在、响应不兼容和上游服务异常。

## 改进

- 账号默认按最近调用时间倒序排列；从未调用的账号排在最后，同时间按账号 ID 倒序。原优先级与质量排序仍可选择。
- 模型测试弹层采用固定标题和操作区，内容独立滚动。模型、并发、样本进度、结果与指纹库状态统一对齐，窄屏自动纵向排列。
- 账号表操作列统一宽度和按钮网格，长名称与窄窗口不会挤压操作按钮。
- Android 的“查看发布页”直接打开本仓库稳定版本的 GitHub Release 页面，不再跳转 APK 文件；macOS 仍打开对应 DMG。

## 修复

- 修复账号调度与快照读取之间的锁互相等待：该问题会阻塞后台检测及整个请求处理，表现为客户端离线、连接和健康检查持续超时。缓存失效改为独立短锁，进行中的旧读取不会重新激活已失效的缓存。
- 管理请求统一使用经过鉴权验证的有效端点。内网端点仅在网络失败或 404 时尝试已配置的公网端点；401／403 和响应格式错误会明确提示，不掩盖鉴权问题。
- 暂时断线时保留已有快照，并通过离线提示与托盘显示连接异常类别。连接检查合并并发读取、限制失败重试，手动重新检查可立即重试。
- 模板迁移保留旧数据和自定义模板，保存失败不会误报成功；旧客户端保存内置模板不会覆盖新增模板。

## 兼容

- 兼容 Sub2API 0.2.14 的管理员 API Key 鉴权与标准管理接口响应，不使用默认管理员密码。
- 模板应用仍需手动确认，仅更新模型白名单与映射；忙碌账号进入现有操作队列。
- 保留额度限频、自动用卡、恢复、ModelTrace、降智报警、分组草稿、记录、配置及 Keychain；不修改 Sub2API 源码、镜像或数据库表结构。
- 云端开发与运维工具迁入独立运维仓库，业务仓库不再携带环境专用的 devhost 工具与清单。
