# Sub2Ops 0.1.58

新增账号创建、配置复用与账户访问令牌显示复制。

- 账号页新增完整添加账号表单，对齐 Sub2API 0.2.11 的十个平台及原生授权、API Key、Bedrock、Service Account 与批量导入入口。
- 支持搜索同平台、同类型账号并一键复用新建参数，保留新账号名称与新填凭据；支持分组、代理、调度、模型映射、额度、协议和平台专属设置。
- New API 账户访问令牌支持“显示并复制”和隐藏，移除清除按钮；留空保存保留原值，查看与复制不触发保存。
- 创建成功后关闭并刷新，批量部分失败保留结果，已成功或结果未知的项不重复提交。授权链接使用系统浏览器打开。
- 统一账号工具栏按钮尺寸与对齐，修正令牌操作间距、授权表单留白、移动端全屏页脚及多行凭据输入高度。
- 前后端同步升级，不新增数据库表或持久化任务。提供 DMG、APK 与 SHA256SUMS。
