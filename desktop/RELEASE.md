# Sub2Ops 0.1.56

修复旧限流误恢复和降智漏处置，新增 IP 管理。

- 跳过限制到期后已成功调用的旧限流恢复候选，取消尚未派发的陈旧任务，保留真实耗尽与新限流恢复。
- 自动降智检测保留首组即时处置，增加有效最终汇总兜底；处置回执、检测日志和通知区分判断依据，不追溯处理旧摘要。
- 功能页分为恢复与检测、模型配置、IP 管理三个标签，切换保留草稿。
- IP 管理提供筛选分页、新增编辑、启停、单个与批量删除、批量添加、JSON 导入导出、关联账号和代理诊断；支持认证、有效期和备用代理。
- 认证默认遮蔽，文件操作使用原生选择器；桌面固定名称与操作列，Android 使用纵向列表和全屏编辑。
- 前后端同步升级，无需业务数据库迁移。保留历史及当前账号状态，不重放已派发请求。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS；覆盖安装保留配置和 Keychain。服务器保留上一版回退镜像。
