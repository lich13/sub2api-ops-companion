Sub2Ops 0.1.3 增加账号优先级与完整连接测试、全量 OAuth 额度刷新和恢复成功历史，并退役模型降级保护。

账号页以紧凑表格展示优先级、调度状态、限流预计解除时间和 Sub2API 用量窗口；优先级数值越小越优先，并通过版本校验写回单个字段。保留查询、次数、重置和探测；不包含点数和邀请。快照刷新只读已有快照与日志。

每组保留最近调用的三个不同账号，快捷账号行仅显示名称、调度开关、两条准确时间和 OAuth 微型用量条。事件页保留恢复成功记录，分别显示测活通过及恢复确认时间。所有格式化时间隐藏年份，使用北京时间 MM-DD HH:mm:ss。快捷窗口预创建并通过菜单栏事件边界定位，重复点击保持显示，保留固定、失焦关闭、Escape、右键菜单及无 Dock 图标。

修复 macOS 27 在常驻右键菜单时吞掉左键事件的问题，按 tray-icon 上游修复改为临时挂载菜单。设置页版本号直接读取构建版本。耗时额度刷新和流式连接测试不再阻塞快照轮询，连接切换会丢弃旧响应。

使用已有 Sub2API 管理员 API Key，保存至 macOS Keychain。连接测试支持 OpenAI 普通、Compact、图像及 Grok 文本、图像、视频、搜索、TTS、STT、Realtime；开始前确认真实请求，取消不重放。全量额度刷新覆盖暂停在内的 OpenAI/Grok OAuth，Grok 只刷新账单。云端需部署本次配套 Companion 接口；现有网页、SSO 和自动化继续保留。

系统要求：macOS 12+，Apple Silicon。首版使用本机签名，未经 Apple Developer ID 签名或公证。检查更新会打开发布页，不自动安装。

安装前可使用 `shasum -a 256 -c SHA256SUMS` 验证下载文件。
