# Sub2Ops 0.1.48

移除账号质量评分，新增自动检测日志，并统一当前 Companion 连接内的自动检测模型。代理质量检测、慢首字线索和降智标记继续保留。

## 自动检测与日志

- 在“功能 → 恢复、测活与模型检测”配置自动检测模型，默认 `gpt-6-luna`。每账号弹窗只编辑启用和间隔；旧每账号模型字段不再决定新任务。
- 新配置只影响新建任务；已有任务和对应恢复核对保留创建时的模型，不补测、不重复用卡。
- “事件 → 日志”展示全部已创建自动检测终态任务，支持刷新、加载更早记录和指定任务详情；不包含手动模型测试或尚未建立任务的原因。
- 验证通过、取消降智标记、恢复调度和 Bark 状态分别显示。摘要不参与业务判断，浏览日志不会检测或推送。
- 修复模型目录被账号映射或默认列表替代的问题：直接读取当前账号请求所用凭据与代理对应的原始供应商目录；失败明确显示，不伪装成模型不支持。
- 更新 TLS 证书验证和根证书依赖，拒绝已撤销信任的证书链。

## 升级与安装

- 账号评分相关入口和旧详情 API 已移除；Mac 默认窗口宽度为 1310，最小宽度仍为 900。
- 不改变数据库结构或状态版本号；全局配置与结果摘要是可选字段。已清除的历史报告显示“历史详情不可用”，不补造结论。
- 新客户端连接旧服务会提示升级并禁用不兼容编辑。配置、Keychain 和业务历史保留，可使用当前兼容状态回退到 0.1.47。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS，不提供 ZIP。
