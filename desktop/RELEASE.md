# Sub2Ops 0.1.74

- 深度重构桌面端与移动端全局界面样式：建立统一的五档控件高度原语与跨平台自定义下拉选择框样式，修复“功能 → 恢复与检测”及多处表单中下拉框与输入框高度坍塌、基线错位、分区标签首次切换样式跳变、设置页卡片宽度不齐及深色粘性列白边阴影等问题。
- 统一全量弹窗与抽屉交互：补齐焦点接管、`Escape` 仅关闭最顶层弹窗（避免菜单栏快捷面板误收起）、连接切换时的残留状态清理、`localStorage` 受限环境容错回退，以及数字输入框编辑过程中允许暂存清空再输入。
- 前端与桌面原生端精简提效：对配置编辑、代理管理、账号创建与重授权弹窗按需拆包，降低首包体积并锁定 Android 12 WebView 兼容构建目标；主窗口最小化或隐藏时自动降频轮询并跳过冗余 IPC 推送，开启原生发布版 Thin LTO 优化。
- 服务端调度与查询减负：用卡策略改为批量预筛候选账号，周期额度任务、空闲自动检测与容量补漏查询按数据版本与时间窗口节流；`/snapshot` 预序列化字节复用并分离统计缓存纪元，状态存储写入后直接刷新内存快照，无代理检测复用共享 HTTP 客户端。
- 服务端内存、磁盘与安全收敛：自动回收终态超过 60 秒的 SSE 事件缓冲，对超量终态通知与任务记录做高水位裁剪，显式删除账号时同步清理对应 Key 额度凭据；指纹库内存剔除原始 JSON 副本并预编译检测矩阵，内置 LM Detector 直接从内存加载，移除未使用的同步网络模块并收敛编译期共享 SQL 模板。
- 修复自动检测处置 Bark 通知连续失败无限重试及错误详情缺少“投递失败”标签、裸 IPv6 代理地址未包裹方括号、配置宿主瞬时连接错误退出及提交失败未恢复原持有状态、代理检测传输错误暴露底层调试信息与非 UTF-8 外部环境变量触发启动异常的问题。
