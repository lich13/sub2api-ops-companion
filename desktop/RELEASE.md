# Sub2Ops 0.1.26

本版本新增慢首字预警，并统一过滤由 Companion 本地限流产生的 429 记录。

完整历史见 [CHANGELOG.md](CHANGELOG.md)。

## 新增

- OpenAI OAuth 与 API Key 按账号分别统计最近 24 小时的有效文本流式调用。最近 10 条中至少 8 条首字时间严格超过 10 秒时，发送一次 Bark 重要提醒。
- 有效调用恢复到 10 秒以内后结束当前预警阶段；已标记“降智”的账号继续静默，但对应记录仍可查看。

## 修复

- 识别明确的本地“每分钟最多请求 N 次”限流证据，并从错误列表、质量统计、恢复判断和容量预警中统一排除。
- 保留真实上游容量错误与并发限流错误，避免把普通 429、503 或客户端限流误判为上游异常。

## 兼容与安全

- 原始错误日志继续保留，额度限频、自动用卡、恢复、模型测试、分组、历史路由和已有配置不受影响。
- 慢首字预警不创建伪造错误记录，也不会额外发起额度查询、测活或模型请求。
- Bark 重要提醒使用现有开关、服务地址和设备密钥；状态文件继续采用原子写入与受限权限。

## 发布包

- macOS Apple Silicon：DMG
- Android ARM64：签名 APK
- `SHA256SUMS`：统一校验文件

系统要求：macOS 12+ Apple Silicon 或 Android 12+ ARM64。不提供 ZIP。
