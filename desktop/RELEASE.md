# Sub2Ops 0.1.99

- macOS 记录页按名单长度展开用户筛选，快速搜索或翻页后仅显示当前结果。默认窗口可查看到 IP 列，冻结用户列、列设置和窄窗口横向滚动继续可用。
- 调用详情补齐分组、请求类型、服务等级、User-Agent、返回差异、分项计费和适用的缓存、图片及视频数据。长字段可完整阅读和复制。阅读历史或打开筛选、详情时保留当前位置，北京时间跨日后可刷新至新的预设范围。
- 「ModelTrace 指纹库」和「LM Detector 检测库」由服务端各自每 24 小时检查一次，支持手动更新。切换检测源可查看对应库和本轮版本。LM Detector 更新后保留当前、上一版及任务仍需的版本。
- 减少记录轮询与翻页的数据库查询、账号快照常驻内存、配置重复解析和恢复历史排序开销。macOS 原生安装包移除闲置网页资源。
- 先升级 Companion 和配置宿主，再更新客户端。沿用现有接口、状态文件和数据库，回退 0.1.98 可使用当前数据。
