Sub2Ops 0.1.2 对齐 Sub2API 用量栏，修复菜单栏左键显示路径，并将快捷面板压缩至 420×560。

用量栏以统计标签、短进度条展示 OpenAI OAuth 5h/7d、Grok 付费 7d/30d、免费 24h，以及 API Key 今日统计和已配置配额。保留适用的查询、次数、重置和探测；不包含点数和邀请。自动刷新只读已有快照与日志。

每组保留最近调用的三个不同账号，快捷账号行仅显示名称、调度开关和两条准确时间。所有格式化时间隐藏年份，使用北京时间 MM-DD HH:mm:ss。快捷窗口预创建并通过菜单栏事件边界定位，重复点击保持显示，保留固定、失焦关闭、Escape、右键菜单及无 Dock 图标。

修复 macOS 27 在常驻右键菜单时吞掉左键事件的问题，按 tray-icon 上游修复改为临时挂载菜单。设置页版本号直接读取构建版本。

使用已有 Sub2API 管理员 API Key，保存至 macOS Keychain。云端需部署本次配套 Companion 接口；现有网页、SSO 和自动化继续保留。

系统要求：macOS 12+，Apple Silicon。首版使用本机签名，未经 Apple Developer ID 签名或公证。检查更新会打开发布页，不自动安装。

安装前可使用 `shasum -a 256 -c SHA256SUMS` 验证下载文件。
