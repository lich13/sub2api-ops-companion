# Sub2Ops 0.1.27

本版本为 OpenAI 账号增加后台模型检测，将账号模型配置改为手动应用的三套模板，并完善指纹库更新与失败恢复。

## 定时检测与预警检测

- 每个 OpenAI OAuth／API Key 账号可单独开启定时检测，默认关闭。默认间隔 15 分钟、模型 `gpt-6-luna`，均可修改。
- 新发生的容量错误或慢首字预警会提交一次自动检测，同账号的重复触发合并处理，不依赖客户端是否打开或 Bark 是否投递成功。
- 自动检测先执行第 1 组。有效样本的首位指纹推测为 `gpt-5.6-luna` 时立即结束、保存降智标记并停止调度；标记结果与停调度核对结果分别展示。该判定不增加匹配度门槛。
- 首组未命中则继续原有最多三组与 99% 提前完成规则。手动测试仍只展示结果，不改变标记或调度。
- 已标记、关闭调度、停用、认证异常或额度耗尽的账号暂停自动检测。人工操作优先；旧任务的迟到结果不会覆盖新操作。

## 账号入口与模板

- 账号页直接提供“模型测试”“标记降智／取消标记”“定时检测”。测试连接、恢复状态与删除移入“更多”。
- 原“账号模型配置”分区及标记自动套用逻辑退休。账号工具栏新增“账号模板”，提供“满血”“降智”“降智接管”三套独立模板。
- 模板支持精确白名单和请求模型映射。仅手动选择账号并确认差异后应用；标记操作和自动检测不修改模型配置。
- 忙碌时进入操作队列，只局部更新账号模型配置，保留凭据、代理、分组、调度及自动化设置。空模板明确表示不限制模型。

## 指纹库更新

- 固定从 ModelTrace 官方仓库读取数据，支持 GitHub API 与官方备用读取路径。按小时检查；临时失败冷却后重试，并尊重服务端限流时间。
- 校验评分器与挑战契约、Git blob、数据摘要、模型顺序及数值结构。兼容性变化提示升级，校验或缓存写入失败继续使用最近有效库。
- 内置库更新至固定提交 `a7edbadabec28fdf8b5cd8181764af80136a668a`，保留许可证，并提供可复现更新脚本及一／二／三组评分对照。
- 模型测试弹层新增版本与“检查更新”。每轮测试固定使用开始时的指纹库，后续更新不会重算旧结果。

## 兼容与数据保留

- 保留额度查询限频、自动用卡、恢复、Bark、Key 回退、分组草稿、记录、路由历史和本地配置。
- 定时检测与指纹库状态独立持久化；重启不重放已派发而未完成的模型请求，也不补跑错过的周期。
- 仅修改 Companion，不修改 Sub2API 源码、镜像或数据库表结构。新安装的账号模板需自行配置，不导入其他安装的账号信息。

## 安装包

- macOS Apple Silicon：DMG（macOS 12+）
- Android ARM64：签名 APK（Android 12+）
- `SHA256SUMS`：统一校验文件

不提供 ZIP。Android 实机功能验收已取消，响应式与 APK 构建检查单独执行。
