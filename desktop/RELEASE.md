# Sub2Ops 0.1.41

关闭批量测活结果后，账号列表不再被摘要横条占位；定时检测补充上次开始时间，快捷面板增加受限状态提示和恢复按钮。

## 账号页

- 关闭结果后移除结果区和摘要行；没有选中账号时隐藏批量操作栏。结果仍可从工具栏的“测活结果”打开，执行中在入口内显示进度。
- 关闭状态按连接保存，后台任务及重复提交保护继续生效；迟到响应不会重新展开。Android 全选入口保留在账号数量与排序行。
- 定时检测显示服务端记录的“上次检测（开始）”，使用北京时间。无记录与时间未知分别显示，刷新或保存设置不会产生检测记录。

## 快捷面板

- 分组和异常列表将当前受限账号标为琥珀色，并提供限制原因提示；仅有历史错误的正常账号保持正常颜色。
- 可恢复账号提供小型“恢复状态”按钮，沿用已有恢复操作，不额外打开调度、解除托管或清除降智标记。
- 保留面板宽度、账号行高、用量和时间列；恢复按钮与错误详情入口独立，支持键盘操作及执行中禁用。

## 安装包

- macOS Apple Silicon：DMG（macOS 12+）。
- Android ARM64：签名 APK（Android 12+）。
- SHA256SUMS：安装包校验文件；不提供 ZIP。

本版同步更新构建工具链。升级保留配置、Keychain、业务状态与历史。
