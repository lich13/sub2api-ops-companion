Sub2Ops 0.1.12 完善调用记录筛选与指标展示。

- API 密钥改为完整目录，支持搜索、分页、所属用户与历史 ID，不再受当前记录页限制。
- 新增用户筛选，并与 API 密钥联动；移除类型列及类型筛选，保留其他列偏好。
- 分色展示输入、输出、缓存读取与写入；突出用户实扣和账户费用。
- 首字与总耗时分别按快慢着色，增加 TPS 输出速度，完善深浅主题下的对齐与层次。
- 保留历史模型路由、自动跟进、OAuth 限频、账号数据、Keychain 和现有自动化；记录及目录读取不会触发额度查询。

系统要求：macOS 12+ / Apple Silicon，或 Android 12+ / ARM64。提供 DMG、固定签名 APK 和 SHA256SUMS，不提供 ZIP。
