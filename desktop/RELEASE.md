# Sub2Ops 0.1.87

- 修复模型配置中输入法 Esc 误关窗口的问题；有未保存修改时忽略遮罩和 Esc，主动关闭时确认是否放弃。刷新、短暂离线和保存失败保留草稿，确认保存成功后关闭。
- 请求详情的费用固定显示 8 位小数、倍率 2 位，Token 保持千分位整数；科学计数法展开为小数，保留大额原始精度以及缺失值与零值的区别，不改变计费数据。
- 手动 API Key 用量、批量 OAuth 刷新及模型目录复用已读取的账号和凭据，按实际需要读回账号详情；保留锁等待、上游请求后及父账号变化核对。
- 模型恢复先核对已有资格，再计算并复用耗尽证据；首样本复用准备结果，保留用卡后、等待并发位和重试时的重新检查。
- 删除未使用的卡观察字段及其校验、不可达的自动查卡和补查分支、退役内部刷新入口和重复判断。旧观察字段随正常状态写入移除，数据库卡快照确认、查询预算、冷却和用卡期限保持不变。
- 支持从 0.1.84 及以后版本升级，无数据库迁移，HTTP 接口保持兼容。保留历史任务识别、展示和扣卡回执；回退沿用当前数据，不恢复旧状态快照。
