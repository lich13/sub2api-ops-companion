# Sub2Ops 0.1.107

- 服务端 CPU、内存与磁盘占用深度优化：移除 ModelTrace 未编译旧版重复线性代数路径，改为强类型流式直编 `CompiledBank` 并按需延迟读取原始 JSON 快照（校验 `sha256` 一致性后缓存），实测空闲常驻内存下降约 26%–33%；LM Detector 在线更新改为落盘精简投影 `unified_bank.compact.json`（单版本由 14.49 MB 降至约 8.3 KB，保留上游 `files` 摘要元数据并兼容既有 `unified_bank.json` 缓存目录）；容量慢首字检测下推标量过滤条件，并采用 30 秒内存窗口加主键尾部有界水位线（`u.id > floor_id`、单次上限 20,000 行且仅关联未删除 OpenAI OAuth / API Key 账号）增量判鲜，捕获乱序提交的同时忽略非 OpenAI 流量；预序列化 `operation_versions` 公共片段、合并单行重复 `to_jsonb`、剥离操作与 OAuth 存储双份强类型常驻堆副本并收口增量事务校验，模型目录缓存原子维护落盘字节上限，空闲挂起操作与优先级后台轮询并修复数据库连接池关闭忙等。
- 双端前端、原生界面与宿主桥接优化：合并精简响应式样式表并拍平冗余覆写层（净减 593 行样式、构建 CSS 体积下降 10%），修复事件页四标签错位网格、统一配置折叠矢量图标并移除批量添加 IP 教学副标题；macOS 桥接在快照修订号未变时复用已解码对象图，Android 应用内更新改为 256 KB 缓冲流式写盘与异步 `spawn_blocking` 落盘校验；修复 macOS `Sub2ApiConfigTabView` 逐键 `O(F²)` 重算与批量添加 IP 断线未提交项提示，单趟分区并复用分组字典（Web 与 macOS），修复 `React.StrictMode` 下批量用量刷新首轮状态丢失、同步终态通知及跨连接切换竞态。
- 请先升级 Companion 与配置宿主，再更新 macOS 和 Android 客户端；沿用现有 HTTP 接口、业务数据库与运行状态格式，回退 0.1.106 详见 `UPGRADING.md`（若在 0.1.107 运行期间在线同步过新的 LM Detector 远程检测库版本，回退前须重置 `lm-detector/state.json` 并移走对应精简库目录）。
