# Sub2Ops 0.1.91

- 新增多 Sub2API 实例管理与丝滑切换：支持保存多个实例备注名与连接地址，各实例管理员 API Key 按规范化 `base_url` 独立存储在系统凭据库（macOS Keychain / Android Keystore）；侧栏、顶栏、设置页与 macOS 菜单栏快捷面板支持一键免输密码切换，缺失或失效凭据自动弹出预填连接框。
- 服务端状态与查询优化：分词器探测与模型测试单组启动改走内存实时进度并移除每步重复账号查询，缩小进度锁范围；修复滚动额度窗口跨整分导致 15 秒快照缓存失效的问题；优先级版本校验提取单字段摘要，操作状态仅在新增终态超限时裁剪并支持单任务局部校验，合并分组设置与测试准备的重复账号读取。
- 依赖更新与门禁加固：吸收 Cargo、Tauri `plugin-dialog` 2.8.4、Python `uvicorn` 0.34.3、GitHub Actions 与 AndroidX（`appcompat` 1.8.0、`material` 1.14.0、`webkit` 1.18.0、`uiautomator` 2.4.0）更新，修复 Android 调试构建符号裁剪与 Python 参考测试并发竞态；重写中英文双语 README 说明。
- 兼容 0.1.84 及以后版本，HTTP 接口、JSON 格式、历史保留数量与业务数据库结构不变；既有单实例偏好配置自动迁移至实例列表。
