# Sub2Ops 0.1.39

账号页多选操作新增“测试连接”。整批提交后，在操作栏下查看总进度、逐账号结果、请求与实际模型、耗时和错误，账号列表始终保留。

## 批量测试连接

- 支持 OpenAI／Grok 的 OAuth 与 Key 账号，一批最多 1000 个。无效、已删除或版本冲突的账号分别反馈，其他账号继续。
- OpenAI 在接受批次时固定服务端配置的测活模型；Grok 使用原生默认文本模式。即使模型不在供应商白名单或目录中，也会提交原生测试接口，不改写账号、分组或白名单。
- 保留原生模型映射；映射前后不同时同时显示请求和实际执行模型。只有明确成功终态显示“测试通过”，上游拒绝时保留失败，不自动换模型重试。
- 沿用测活并发配置、全局任务上限和账号／共享凭据互斥。忙碌账号等待，其他账号继续；“停止未开始”只取消尚未派发的项目。
- 切换筛选不改变已接受批次；离页返回或重启客户端后按连接恢复结果。提交超时用同一请求 ID 找回批次，旧连接响应不会写入新连接。
- 服务重启后接续未派发任务；已派发但结果不确定的项目标为“待核对”，不自动重测。批量持久化只保存必要摘要，不保存模型正文或凭据。
- 单账号测试、ModelTrace、自动恢复、用卡和通知的选择规则保持兼容。

## Rust 隔离原型

- 新增 Axum／Tokio、Reqwest／Rustls、SQLx PostgreSQL 实验服务，复现本轮批测的鉴权、查询、持久化、去重、并发互斥、SSE、取消和重启行为。
- 共用合成数据与模拟上游，在同一 Linux x86_64 CI 环境比较 Python 功能切片与 Rust；完整 Python 服务单列参考。复现步骤位于 `experiments/connection_probe/README.md`。
- 原型不进入生产路由，也不自动替换现有服务。

## 安装包

- macOS Apple Silicon：DMG（macOS 12+）。
- Android ARM64：签名 APK（Android 12+）。
- SHA256SUMS：安装包校验文件；不提供 ZIP。

升级保留配置、Keychain、业务状态与历史。生产验收仅执行只读检查；真实账号批测未实测，安卓实机验收取消。
