# Sub2Ops 0.1.35

账号页新增独立的模型与代理编辑，优先级、并发和负载因子改用统一浮层输入。修复质量统计容易超时、缺少首字便丢弃整条调用的问题，并收紧账号与记录布局。

## 新增

- 账号和分组的“更多”菜单新增“模型白名单”“模型映射”“选择代理”，按平台及账号能力开放。模型配置使用同一个弹层，保存前保留草稿；单账号编辑不修改账号模板或分组白名单。
- 模型配置支持同步上游模型目录，搜索、勾选后加入草稿，再明确保存。新同步项默认不勾选，已有白名单和映射保留；冲突项就地提示，也可手动输入模型及映射规则。
- 代理选择支持搜索和“不使用代理”，只展示名称、ID、协议与状态。继承代理或模型配置的账号明确显示限制，不绕过母账号及透传规则。
- “调度参数”集中展示优先级、并发和负载因子。点击数值打开编辑浮层，支持增减、Enter 保存、Escape 取消；负载因子可选“自动”。

## 改进

- 桌面账号名称列默认收起，可在表头展开并保存偏好。长名称省略显示，悬浮或聚焦可查看完整名称，保留真实 ID、平台、类型和状态；安卓继续使用账号卡片。
- 数字输入采用固定宽度，允许编辑中暂时清空，滚轮不会误改数值。后台刷新不覆盖草稿，保存失败保留输入；排队与实际生效分别反馈。
- 记录表收紧表头、单元格、堆叠字段和工具栏间距，保留现有字号、完整字段、自动加载、阅读位置及精确消费汇总。移动端减少卡片留白，保留触控尺寸。
- 质量详情分别展示成功率、首字和输出 TPS 的有效样本数与缺项原因。缺少首字只影响首字维度，不再排除整条调用；输出 TPS 使用输出 Token 除以总耗时，与记录页保持一致。

## 修复

- 质量查询改为直接读取必要字段，去掉大批调用记录的整行 JSON 转换；兼容可选字段缺失，保留只读查询、超时和记录数量上限。
- 区分“调用不足”“首字未记录”“暂无可比基准”和“统计更新失败”。统计临时失败保留上次明细及计算时间，不将持续有调用的账号误表述为没有使用，也不把旧评分冒充最新结果。
- 修复优先级保存按钮挤压输入框、数字被遮挡的问题，统一标签、数字、图标和操作区对齐。
- 调度参数写入会核对任务归属并衔接已有恢复和用卡状态，避免无关参数变化让流程永久等待；人工调度、凭据、代理及新阻断变化仍优先保护。

## 兼容

- 参数、模型与代理写入复用持久化操作队列，按相关字段校验版本；忙碌时排队，真正冲突保留原因，超时先读取实际值，不盲目重放。
- 模型配置只局部更新 `credentials.model_mapping`，代理只更新对应字段；保留其他凭据、分组、调度和自动化设置。同步模型目录不发送生成、测活或额度请求。
- 保留原质量权重与证据门槛；依据不足时不伪造总分。正常缺项使用中性状态，失败与过期情况明确区分。
- 旧接口及快照保持兼容，保留配置、Keychain、账号模板、分组草稿、自动检测、额度预算、自动用卡、恢复历史和通知队列；不修改 Sub2API 源码、镜像或数据库表。
