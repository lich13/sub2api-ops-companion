# Sub2Ops 0.1.80

- 修复验证失败后新周期额度仍被旧退避阻塞的问题，保留模型排队、冷却与连接重试策略；残留阈值暂停不再覆盖原恢复意图和历史。
- 人工取消只约束当时的额度周期，提前重置或截止时间向后修正后可按新窗口重新立项。
- 旧状态迁移与额度观测摘要复核移至文件载入，普通事务复用已校验缓存；保证浮点数在缓存与重启读取之间保持一致。
- 停止等待中用卡任务的无变化刷盘，已结束任务回到普通库存刷新；保留状态变化记录及现有时钟判断。
- 合并连接恢复和自动用卡中的重复查询、状态保存，保留暂停归属、人工控制、异步模型回执及写后确认。
- 暂停期间修改优先级、并发与负载参数，在上游确认成功后一次同步归属；移除改参预写与跨重启协调。
- 自动模型采样复用同一次账号观测，合并耗时与终态保存；后台读取暂时失败时保留任务，复核已有结果时不重发模型请求。
- HTTP 接口、状态文件版本及模型配置复核方式保持兼容。
