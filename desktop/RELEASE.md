# Sub2Ops 0.1.89

- 模型测试立即取得执行锁时复用账号数据，手动任务优先级使用轻量查询；等待后的账号变化仍会阻止旧目标执行。历史测试仅清理仍保留详情或重试状态的任务。
- 恢复任务兼容查找减少临时集合和重复扫描，保留旧请求键幂等；合并同一准备阶段的重复余额判断，保留异步操作后的有效复核。
- API Key 余额查询减少完整账号重读，远程结果返回后继续核对父账号和凭据变化；原生用量更新后的状态读取保持不变。
- 退役信用字段在状态加载时规范化，后续正常写入落盘；减少重复清理，保留历史、通知、暂停归属及扣卡回执。
- 模型候选复用已读取账号，删除无关平台的 OpenAI 设置查询；修复 Anthropic API Key 候选目录只读取第一页的问题，完整分页成功后才保存新结果。
- 账号目录统一优先使用子账号显式代理，未配置时继承父账号；清理创建目录中无效的 OAuth 请求头适用项。
- Sub2API 版本面板复用配置页已知版本，减少重复请求；确认升级生效后同步运行标识，保留未保存草稿并提示已有冲突。配置宿主不可用时仍可独立查询版本。
- 兼容 0.1.84 及以后版本，HTTP 接口与状态格式不变，无业务数据库迁移。已有模型候选缓存可通过刷新更新为完整目录。
