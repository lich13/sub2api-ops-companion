Sub2Ops 0.1.11 整合功能页，新增调用记录。

- 模型配置并入功能，与 OAuth 恢复、每日测活和 Key 调度回退同页展示。
- 调用记录支持筛选、分页、列偏好、自动跟进和完整详情。
- 按历史证据展示请求、映射、转发和上游返回模型，突出返回差异与推理强度变化。
- 保留 Token、缓存、费用、延迟、User-Agent、IP 等字段；记录读取不会触发额度查询。
- 保留 0.1.10 的 OAuth 限频机制、账号数据、Keychain 和现有配置。

系统要求：macOS 12+ / Apple Silicon，或 Android 12+ / ARM64。提供 DMG、固定签名 APK 和 SHA256SUMS，不提供 ZIP。
