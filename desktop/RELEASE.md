# Sub2Ops 0.1.70

- 批量操作读取复用共享快照，更新进度时仅提取任务状态，减少历史数据复制，保留取消、执行前复核、兼容回退及未知结果保护。
- 告警回扫已处理日志且无需更新游标或清理过期记录时跳过空事务，保留检查频率、迟到日志处理及状态校验。
- 分组和优先级面板隐藏时跳过展示计算，优先级列表加载后减少备用列表构造，保留草稿、后台提交结果及重新进入时的刷新和冲突提示。
- 并列优先级分组逐项追加账号，减少数组复制，保留账号顺序、并列宽度、空槽及拖动行为。
- 修复连续选择测试素材时旧文件晚返回覆盖新素材的问题；切换模式、素材类型或关闭窗口时中止旧读取，读取中禁止提交，失败时明确提示。
- 模型待办直接提取摘要字段，减少完整测试详情复制，保持待办状态、详情接口、持久数据格式及历史保留规则兼容。
