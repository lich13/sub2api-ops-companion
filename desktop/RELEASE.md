# Sub2Ops 0.1.98

- macOS 原生客户端“记录”页滚动到接近底部时自动读取下一页，与旧前端一致，不再需要点击“加载下一页”；分页出错时仍可点击“重试加载”。
- 修复 macOS 原生客户端“记录”页“推理强度”列的实际档位行（如 `↳ medium`）与“端点”列的 `/v1/chat/completions` 被截断的问题；Token 列恢复旧前端宽度，超长数值缩小显示，不再换行。
- 服务端清理分组模型目录下线后的残留：移除已无读取方的上游目录缓存与无用代码，已下线的 `/api/desktop/v1/model-groups*` 路由纳入 404 契约测试；接口行为不变。
- 客户端需与服务端同版本：请先升级服务端再更新客户端；HTTP 接口、JSON 状态格式与业务数据库结构不变，回退 0.1.97 沿用保留的旧镜像与当前数据。
