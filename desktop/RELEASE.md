# Sub2Ops 0.1.52

分组移组仅保留拖拽，两个管理面板增加账号调度开关，简化操作结果、支持批量恢复状态，以及 OpenAI Key 独立检测模型。

## 账号与分组

- 移除分组账号点击选中、独立目标选择条和点击区域移组；保留鼠标拖拽、移动端长按、草稿撤销和统一应用。
- 分组及优先级账号行提供调度开关，沿用托管确认和回读保护，调度操作不修改移组或排序草稿。
- 账号多选增加“恢复状态”，只恢复可恢复账号，汇报已恢复、无需恢复、失败及待核对数量。复用服务端操作队列与幂等保护，不额外启用调度、测试连接或消费重置卡。

## 检测模型

- OpenAI Key 账号定时检测可单独指定模型或跟随全局，候选与模型测试共用上游目录，模型测试默认选中已指定模型。所选模型不可用时保留选择并提示。

## 结果展示

- 优先级移除进度方框和逐项详情入口；执行中显示简短进度与等待原因，结束结果在 3 秒后消失，必要时仍可重新核对。
- 批量测试连接的成功、失败、取消及待核对结果均在整批结束 3 秒后自动收起，可通过“测活结果”重新打开；手动重新查看不自动关闭。单账号测试弹窗不变。

## 升级与安装

- 批量恢复需要 0.1.52 服务端；扩展现有批量操作接口，不改数据库结构和优先级协议。检测状态新增可选模型选择，排序与操作历史继续保留。
- 回退 0.1.51 使用当前状态及保留镜像，先停止新版写实例，已完成的修改不回滚；旧客户端没有批量恢复入口；0.1.51 忽略独立检测模型，恢复使用全局模型。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS；覆盖安装保留配置和 Keychain。
