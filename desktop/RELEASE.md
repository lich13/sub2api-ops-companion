# Sub2Ops 0.1.40

批测结果现在可以随时关闭，Companion 服务端改为完整 Rust 实现。

## 账号页

- “关闭结果”在提交、执行、完成及失败状态均可使用，立即释放账号列表空间；后台任务继续，结果仍保留。
- 关闭后使用“查看测活结果”重新打开，执行中显示进度摘要。隐藏状态按连接保存，迟到响应、离页返回和重启不会强行展开；主动提交新批次会展开。
- “停止未开始”继续只取消未派发项，关闭结果不会解除重复提交保护。兼容已有批次和本地存储记录，支持键盘与移动端触控。

## Companion 服务

- 服务端采用 Axum／Tokio、Reqwest／Rustls 和 SQLx PostgreSQL，生产镜像不含 Python，也不挂载源码执行目录。
- 保留账号、分组、模型目录、人工操作队列、连接测试、ModelTrace、自动恢复、每日测活、用卡、Key 回退及通知功能，兼容 0.1.39 客户端接口与状态。
- 保留现有配置、任务、预算、冷却与历史；人工操作优先。未派发任务可接续，已派发且结果未知的请求先核对，不自动重放。
- 提供只读状态检查与运行模式；实现类型和构建提交可通过 capabilities 核对。测试从固定旧提交取得 Python 对照，资源比较使用同环境下的两个完整服务。

## 安装包

- macOS Apple Silicon：DMG（macOS 12+）。
- Android ARM64：签名 APK（Android 12+）。
- SHA256SUMS：安装包校验文件；不提供 ZIP。

升级保留配置、Keychain、业务状态与历史。生产验收仅执行只读检查，真实账号批测未实测；安卓实机验收取消。
