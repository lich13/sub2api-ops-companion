# Sub2Ops 0.1.50

新增全局优先级管理，收窄桌面记录表，并将自动检测日志改为横向表格。

## 优先级

- 当前连接全部未删除账号跨平台排序，包含停用及不可调度账号。拖动、键盘或上移／下移调整草稿，支持撤销、放弃及重复／稀疏编号的统一重编号。
- 应用后由服务端持久化任务串行保存为 `0..N-1`，最终全量回读一致才完成。关闭客户端后任务继续；取消仅停止未派发项，已派发项先核对，未知结果不自动重发，部分成功不回滚。
- 筛选仅供查看，清除后恢复编辑；不可编辑账号需要改值时阻止整次应用。外部增删或改值会停止剩余修改，重新核对后生成新草稿。
- 账号页优先级只读，仍可排序；并发及负载因子继续原位编辑。本机排序记忆、分组及其他自动化行为保持原样。

## 记录与日志

- 桌面记录表收窄列宽及内边距，长模型路由保留多行、省略提示及完整详情；数值不裁切，双徽章允许换行。移动端卡片和详情保持原有字号及触控尺寸。
- “事件 → 日志”固定十列，窄屏横向滚动。首组／汇总预测和匹配度分别展示，处置、模型验证、取消标记、恢复调度与通知使用独立状态徽章，支持深色模式及键盘打开指定任务详情。
- “未确认降智”保留原含义，不等于模型正常；执行完成或通知成功不会把整条记录标成正常。日志浏览不触发检测或通知，分页与历史摘要规则不变。

## 升级与安装

- 新增独立 `account-priority-orders.json`，不改变数据库结构或已有状态版本。0.1.49 忽略该文件，回退保留当前状态与已写优先级；再次升级先核对进度。切换前停止旧写实例，禁止双实例执行。
- 新客户端连接旧服务时优先级页只读并提示升级，不回退为客户端逐项保存。排序成功只保证核验时编号唯一，上游后续人工修改仍可能改变结果。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS，不提供 ZIP；覆盖安装保留配置和 Keychain。
