# Sub2Ops 0.1.67

- 单次预约与持续预约每个周期的最终成功、失败或需确认结果支持 Bark 通知，合并中间重试，主动取消不推送；通知发送失败继续重试发送。
- 预约连接测试和额度恢复连接测活默认在失败结束 10 秒后重试，最多额外 3 次；可在“功能 → 恢复与检测”修改间隔和次数，0 次关闭自动重试。
- 重试等待释放执行槽，每轮参数与次数在重启后保留；设置修改对新一轮生效，未知结果和授权失效不自动重测，操作待办显示次数和下次时间。
- 持续预约批量读取账号与限流证据，终态操作释放授权副本；目录预览与公开目录共用缓存上限和过期清理，Tokenizer 复用只读数组。
- 余额查询接入服务任务管理，停止或异常时释放查询资源；删除账号及完整列表刷新后清理对应内存样本，保留现有账号样本和持久设置。
- 移除已不生效的“单轮账号上限”设置控件，保留旧配置兼容。
