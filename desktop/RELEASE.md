# Sub2Ops 0.1.96

- ModelTrace 内置指纹库更新到上游 `477d59d5`（2026-11-14 构建，17 → 36 个模型），新增 Claude Fable 5 系列、Claude Haiku 5.5、GPT-6.1 / 6.2、Gemini 4、DeepSeek V4.1、GLM-5.3、Kimi K3 等 19 个模型；分析器版本不变。服务端已保存的指纹库早于新内置库的，启动时自动换成内置库，不早于内置库的保持不变。
- ModelTrace 在线更新接受上游 `477d59d5` 的评分源：它与此前固定的评分源只多一个本服务不使用的输出标记，0.1.95 会把它判为不兼容。
- 修复 macOS 原生客户端“模型配置”读取分组失败、整页不可用的问题；添加模型时修改模型 ID 会重新读取该模型自身的思考档位，不再沿用上一个 ID 的档位。
- 客户端需与服务端同版本：请先升级服务端再更新客户端；0.1.84 及以后版本可直接升级，HTTP 接口与业务数据库结构不变。回退到 0.1.95 前须移走 ModelTrace 指纹库状态文件，详见升级说明。
