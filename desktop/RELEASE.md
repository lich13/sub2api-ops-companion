# Sub2Ops 0.1.90

- 模型测试接收与分析进度在内存中实时展示，派发、分组结果、重试、处置及终态继续落盘；取消与正常关闭保留最新进度，突然退出最多丢失最近的展示阶段细节。
- 模型测试单任务更新仅校验改动记录，历史裁剪集中到记录变化节点；状态文件跳过无变化事务的重复校验，并直接写入临时文件，减少历史积累后的 CPU、内存和重复写盘。
- 模型测试立即执行时复用已准备账号、连接与目录校验，实际等待后重新读取；独立账号的分词器探测复用凭据读取。
- 恢复任务按既有请求键复用，移除旧键全表扫描和重复模型变化检查；已准备任务使用开始时的模型，后续任务使用新设置。
- API Key 余额刷新移除多余账号重读；修复原生额度查询成功续期 OAuth 凭据后被误报为账号冲突的问题。手动刷新后的余额补查保持不变。
- 模型目录分页复用解析时的原始条目计数，保留分页、去重和总量限制。
- Sub2API 版本区域直接使用配置页已知版本，保留手动检查更新、重启确认和未保存草稿；配置宿主读取失败时不再自动发起独立版本查询。
- 兼容 0.1.84 及以后版本，HTTP 接口、JSON 格式、历史保留数量与业务数据库结构不变。
