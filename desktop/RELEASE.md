# Sub2Ops 0.1.71

- 账号模型目录持久缓存，模型测试、连接测试、定时检测和全局模型选择共用；重新打开直接读取缓存，可手动刷新，相关账号配置变化后重新获取。刷新失败保留已有选择，认证失效清除旧目录。
- 分组管理和优先级入口覆盖全部实际平台，补齐平台名称；继续按平台应用草稿、撤销、并列优先级及冲突检查，拒绝跨平台分组。
- 记录增加平台筛选，列表、总消费、分页和新增计数使用同一条件；桌面筛选保持单行，手机沿用筛选弹层。
- 恢复历史增加实际测试尝试次数，包含首次执行；未执行取消为 0，无法确认次数的旧记录显示“—”。
- 测活模型和自动检测模型支持选择来源账号、搜索候选及手动刷新，并保留手动输入模型 ID；来源账号不改变执行范围。
- 统一新增控件的字体、对齐和尺寸，移除重试设置说明，保留预约测试与额度恢复共用重试设置的原有规则。
