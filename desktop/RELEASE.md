Sub2Ops 0.1.6 为 OpenAI、Grok 的 OAuth 和 API Key 账号增加历史质量评分。

- 账号表显示 0–100 分、红黄绿三档和简短问题标签；支持质量排序、筛选及明细，默认仍按优先级排序。
- 近 7 天可观测失败率占 50%，同模型校正的首字与输出速率各占 25%；近期表现优先，正常额度耗尽不扣分，重试成功保留原账号失败。
- 基准按模型、推理档位、服务档位、传输方式和输入规模匹配，账号等权；样本或覆盖不足显示黄色“样本不足”，严重故障单独标红。
- 独立只读缓存按需计算，不阻塞实时快照，不查询额度或调用模型，不修改优先级、调度及配置。计算失败保留结果，超过五分钟显示数据过期。
- 保留 Keychain、账号操作、用量、自动恢复、每日测活、Bark、两平台 Key 回退及菜单栏行为。需同时部署本版 Companion 接口。

系统要求：macOS 12+，Apple Silicon。使用已有管理员 API Key 与 macOS Keychain。本版为本机签名，未经 Apple Developer ID 签名或公证。检查更新打开发布页，不自动安装。

安装前使用 shasum -a 256 -c SHA256SUMS 校验下载文件。
