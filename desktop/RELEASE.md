Sub2Ops 0.1.18 修复记录与事件页面切换时的重复面板和过期错误响应。

- 记录、事件、账号、功能和设置使用唯一 keyed 页面表面，分组管理单独保留草稿状态，重复挂载和页面残留不会再出现。
- 事件页保留完整上游与认证错误历史，分页和刷新串行去重；当前错误与历史／已解决错误明确区分。
- 连接切换、离开页面、详情关闭后，旧的记录、事件和详情请求结果不会回写当前界面。

此前版本的账号可视化分组与 Codex OAuth「疑似降智」重要报警继续保留。

- 独立「分组」页面以相交区域管理 Codex / Grok；拖放、点选和键盘修改先保存为草稿，再统一应用。保留范围外归属，冲突和部分失败保留未提交修改。
- 安卓由账号页进入分组管理，保留五项底部导航与纵向布局。
- Codex OAuth 的两类指定过载／容量错误逐条发送 Bark 重要警告。后台独立只读采集，不触发额度查询或模型请求。
- 账号、分组与错误详情支持「标记降智／取消标记」。标记按账号 ID 持久保存，停止该账号的此类报警并取消待发项；取消后仅提醒新错误。
- 保留自动用卡、额度限频、恢复、Key 回退、历史真实路由、有效配置与 Keychain。仅修改 Companion，不修改 Sub2API 源码、镜像或表结构。

系统要求：macOS 12+ / Apple Silicon，或 Android 12+ / ARM64。提供 DMG、固定签名 APK 和 SHA256SUMS，不提供 ZIP。
