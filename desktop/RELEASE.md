# Sub2Ops 0.1.88

- Sub2API 配置页新增版本检查、发布链接、更新与重启生效；复用原生更新缓存，长更新请求单次提交，断连不自动重放，重启后仅在当前页面短时核对运行版本。
- 重新授权使用原生保存接口返回的脱敏账号状态确认结果，成功后刷新账号；修复优先级面板在能力加载期间误报不支持的问题，刷新保留编辑草稿。
- 添加账号表单保护输入法 Escape 和未保存草稿；保存单个账号模板后保留其他模板的修改。
- 创建字段与静态目录对齐 Sub2API 0.2.20：新增 TypeSafe / Jev、Command Code、Cline；Gemini Vertex 支持 API Key，Vertex 服务账号补齐额度设置。
- Gemini 自定义上游支持显式缓存和最大 TTL；OpenAI 支持图片规格选择；协议规则支持首选及多个协议，临时停用规则支持模型或账号范围，旧规则保持原语义。
- 更新创建模型、映射、协议与地址默认值，保留用户修改的草稿；统一 OpenCode Go 平台标识。配置目录新增 0.2.20 的八个字段，不修改已有生产配置。
- 批量额度、API Key 余额、模型目录与并行样本复用准备数据，减少重复 SQL；保留等待、重试与实际远程请求后的有效复核。恢复任务优先按请求键查找，保留旧任务匹配。
- 精简无消费者的信用状态及写入，保留暂停归属、控制代次、通知去重、扣卡回执和有效历史。兼容 0.1.84 及以后版本，无业务数据库迁移；回退沿用当前数据。
