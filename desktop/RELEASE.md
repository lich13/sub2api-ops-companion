# Sub2Ops 0.1.93

- 修复原生客户端“刷新模型列表”被拦截并提示“客户端不允许此操作”的问题，测试连接、模型测试、定时检测和账号模型设置中的刷新恢复可用。
- 移除只读验收模式（`--read-only`、`--check-state`）和两个历史迁移子命令（`migrate-oauth`、`migrate-desktop`）；每次启动仍执行相同的配置、状态和数据库校验。
- 移除 0.1.84 起客户端已不使用的直连账号接口、旧排序库、历史设置项和批量任务的逐账号回退；账号写操作统一经操作队列，不带 `schema=2` 的优先级请求返回 `client_upgrade_required`。
- 客户端需与服务端同版本：请先升级服务端再更新客户端；0.1.84 至 0.1.92 的客户端可继续连接 0.1.93 服务端。
- 0.1.84 及以后版本可直接升级，状态格式与业务数据库结构不变；更早的版本请先升级到 0.1.84 至 0.1.92。
