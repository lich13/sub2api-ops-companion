# Sub2Ops 0.1.95

- 修复 macOS 原生客户端账号页提示“请求参数无效，请刷新后重试”（422）的问题：用量查询、次数、探测、使用重置卡和批量连接测试的请求补齐服务端要求的字段。
- 修复 macOS 原生客户端按钮只有文字或图标本身可点的问题：侧栏切换、表头、菜单行、折叠标题等整块区域均可点击。
- 修复 macOS 原生客户端添加账号以及 Codex Session、Codex PAT、Grok SSO 导入始终被拒绝的问题；添加账号表单补齐到期时间、协议地址、模型协议规则、临时不可调度规则、预设地址、自定义错误码确认与凭据文件导入，创建结果未知的条目不会重复提交，行为与 Android 客户端一致。
- 修复 macOS 原生客户端读取账号模型列表被拦截并提示“客户端不允许此操作”的问题；余额刷新设置可关闭自动刷新，间隔范围恢复为 10–86400 秒。
- 服务端功能不变。客户端需与服务端同版本：请先升级服务端再更新客户端；0.1.84 及以后版本可直接升级，状态格式与业务数据库结构不变。
