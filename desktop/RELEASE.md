# Sub2Ops 0.1.97

- 修复 macOS 原生客户端账号页“调度参数”标签与数值槽位错位、悬停编辑框未铺满右侧槽位的问题；“记录”页恢复与旧前端一致的紧凑固定列宽与表头间距，时间戳、费用、延迟保持单行完整显示。
- LM Detector 内置检测库与评分门控更新到上游 `33fb43f2`（2026-11-17 构建，66 → 72 个模型，新增 `muse-ember`、`claude-fable-5.2`、`gemini-4-carbon`、`gemini-4-hydrogen`、`gpt-6.2-sol`、`gpt-6.2-astra`，并启用相邻对重复比例序列门控）；仍指向历史内置版本的服务端启动时自动切换至最新内置库，已在线更新到其他远程版本的保持不变。
- 彻底移除分组“模型配置”与网关模型目录覆写功能，“功能”页精简为恢复与检测、IP 管理、Sub2API 配置三个标签；单账号“模型白名单/映射”、账号模板与单账号模型列表查询保持不变。吸收容器基础镜像、前端与 Rust 依赖更新。
- 客户端需与服务端同版本：升级服务端时须先按升级说明拆掉旧模型目录网关转发片段并重载 Nginx，再切换 0.1.97 容器，最后更新客户端；回退 0.1.96 详见升级说明。
