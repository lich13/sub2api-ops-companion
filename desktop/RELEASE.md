# Sub2Ops 0.1.77

- 修复重新授权保存缺少上游必填类型的问题；粘贴回调地址或查询参数立即提取授权码并校验状态，保存后回读确认，结果未确认时不自动重发。
- 记录页选择平台、用户、账号、密钥及返回差异后立即刷新；模型输入停顿 300ms 或回车生效，移除提交筛选按钮。
- 每个账号增加严格与宽松判定模式。严格模式保留现有逻辑；宽松模式等待全部有效采样，仅最终汇总明确匹配指定模型时判降智，默认目标为 `gpt-5.6-luna`。
- 手动测试、定时检测、错误触发、降智复查与恢复验证共用账号规则；任务和重试保留创建时的规则，历史结论保持原值。
- 合并单次采样的组结果与汇总写入，优化日志分页排序，恢复验证与保活复用只读状态快照，减少重复序列化和深拷贝。
- 新增判定控件沿用系统字体、主题颜色与控件尺寸，桌面整齐分列，手机顺序换行。
