# Sub2Ops 0.1.92

- 新增批量使用重置卡：账号多选后点「使用重置卡」，确认页列出有卡账号的 7d 用量与可用卡数，没有可用卡的账号自动跳过；确认后逐个使用并实时显示每个账号的结果，关闭对话框即停止尚未开始的账号，不自动重试。
- 修复「次数」查询自 0.1.87 起始终提示操作未确认并滞留在待办的问题：Sub2API 保存的卡快照不带采集时间，现改为按本次返回的卡数与已保存快照一致来确认。
- 查询、次数、探测失败后直接结束为失败并保留原因，不再停在「需确认」占用待办；使用重置卡的结果不确定保护不变。
- 自动用卡仍只在 7d 满额且上游限流后的五分钟内执行，之后才发放的卡不补用；修复功能关闭或服务停机期间恢复的账号在下一个 7d 窗口限流时被当作旧一轮而跳过的问题。
- 兼容 0.1.84 及以后版本，HTTP 接口、JSON 格式、历史保留数量与业务数据库结构不变。
