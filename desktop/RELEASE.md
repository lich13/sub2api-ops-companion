# Sub2Ops 0.1.57

新增 API Key 余额探测与自动刷新，调整账号、记录和设置交互。

- API Key 用量列新增 Sub2API / New API 余额、Key 配额、多套餐与额度窗口、重置和到期状态，以及可折叠的上游用量统计；现有今日统计与配置额度分别保留。
- 快捷面板显示简要余额。自动刷新默认 60 秒，可在账号页工具栏关闭或设为 10–86400 秒；仅在账号页或快捷面板前台查询到期结果。手动与自动刷新遵守上游重试时间，失败保留上次成功余额。
- 用量列可配置 New API 独立账户访问令牌；支持新增、替换及明确清除，留空保留。令牌仅保存在服务端。
- 记录页固定时间列移至账户列之前；返回账号页时清空筛选、勾选和临时弹层，恢复局部展开与滚动位置，保留排序和名称显示偏好。
- IP 管理采用紧凑列宽和两列操作按钮；设置弹窗保存成功即关闭，批量全部成功后关闭，失败或结果未确认时保留输入。
- 预约测试支持秒级时间，新增“最近周期 +3 秒”一键填入当前账号最近有效的周期重置时间加 3 秒，确认后再提交。
- 前后端同步升级，无需业务数据库迁移。余额配置随现有数据目录持久化，查询缓存仅保留在内存。
- 提供 Mac Apple Silicon DMG、签名 Android ARM64 APK 和 SHA256SUMS；覆盖安装保留配置和 Keychain。服务器保留上一版回退镜像。
