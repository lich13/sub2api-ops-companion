Sub2Ops 0.1.5 压缩菜单栏快捷面板，增加账号删除与恢复状态，并调整事件页面。

- 快捷面板宽 420px、最高 520px，随内容缩短；单行工具栏和紧凑账号行保留微型额度、两项准确时间及调度开关。
- 支持单个及批量删除，确认时列出账号与托管解除；最多并发三个账号，逐个显示结果，失败不自动重试。
- 恢复状态复用 Sub2API 操作，不额外切换调度、查询额度或测试模型。
- 上游与认证错误、恢复成功改为并列标签；已删除账号从分组动态与恢复列表中排除，底层历史保留。
- 保留 Keychain、自动恢复、每日测活、Bark、两平台 Key 回退以及现有菜单栏和 Dock 行为。需同时部署本版 Companion 接口。

系统要求：macOS 12+，Apple Silicon。使用已有管理员 API Key 与 macOS Keychain。本版为本机签名，未经 Apple Developer ID 签名或公证。检查更新打开发布页，不自动安装。

安装前使用 shasum -a 256 -c SHA256SUMS 校验下载文件。
