# Sub2Ops 0.1.83

- Bark 仅在确认降智时使用重要通知和警报音，包括合并进用卡结果的降智提醒；用卡成败、检测恢复正常及其他提醒改为普通通知。
- 修复用卡验证成功后清状态失败无法再恢复的问题；只重试清状态和启用调度，沿用原截止时间，不重复扣卡或已成功的测试。
- 普通恢复在清状态超时、未生效或读回失败后保存最小测活成功结果，按原退避和次数限制重试；正常 token 续期可继续恢复，真实身份变化或新阻断重新评估。
- 手动用卡在连接测试结束后读取账号最终状态，再保存恢复结果和通知，保持单次扣卡、单次连接测试。
- 合并改参、用卡、批量分组、持续预约及模型启动的重复查询；模型排队先取得执行名额，保留手动优先、父子账号锁、网络操作后的核对与凭据输出过滤。
- 精简额度观测、旧用卡策略、保活账本和复查恢复分支；降智处置成功仅保存最终状态，停调度失败保留 pending 并由现有巡检重试。
- 审计日志读取不再创建文件或修改权限；保留 20 MiB 轮转、读取锁和输出脱敏，移除旧超大日志裁剪。
- 支持从 0.1.82 升级，保留设置、历史、待处理任务和扣卡派发记录；HTTP 接口不变。精简后的状态不能直接交给旧镜像读取，部署失败保留当前状态并修复，不恢复旧扣卡记录。
